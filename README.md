# 教材データ・パッケージ索引

## 目的

語学、教養、美術、理科の学習データを、用途と形式から選べるようにまとめたリポジトリです。

## リポジトリ索引

| 項目 | 内容 | 形式 |
|---|---|---|
| [000001.csv](000001.csv) | 英日対訳、2,286行 | ヘッダーなし・2列のCSV |
| [000002.csv](000002.csv) | 初級英会話・語彙、206行 | CSV |
| [000003.csv](000003.csv) | 色彩理論・絵画、62行 | CSV |
| [000004.json](000004.json) | 基礎・地理・歴史を扱う500枚のカード | JSON |
| [000005/README.md](000005/README.md) | 小・中学校理科857枚のカード | 複数ファイルからなる教材パッケージ |
| [LICENSE](LICENSE) | 利用条件 | ライセンス文書 |

## おすすめの使い方・読む順序

1. 上の索引で目的に合う教材を選びます。
2. CSVは軽量な表形式データとして確認・取り込み、特に`000001.csv`はヘッダーを付けず2列として扱います。
3. 一つのカード集として扱う場合は`000004.json`、理科を体系的に学ぶ場合は[000005/README.md](000005/README.md)から読み始めます。

各教材は独立しているため、番号順にすべて読む必要はありません。

## 形式について

- CSVは単一ファイルの表形式データです。
- JSONは構造化された単一のカード集です。
- `000005`はREADME、表、Anki用データなどを含むディレクトリ型パッケージです。
