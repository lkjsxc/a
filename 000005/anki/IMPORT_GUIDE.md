# Ankiへの読み込み

## 初学者：最初の150枚

最初は `science_core_first_150.tsv` を読み込む。探究の道具20枚から始まり、小3→中3の順で領域を小刻みに交替する。8〜10日で一巡してから全体版へ進む。

## 全857枚：タグ付きTSV

1. Ankiで **ファイル → 読み込む** を選ぶ。
2. 全体版では `science_tagged.tsv`、開始版では `science_core_first_150.tsv` を選ぶ。
3. ノートタイプは「基本」またはFront/Backの2フィールドを持つものを選ぶ。
4. 列はFront→表面、Back→裏面、Tags→タグに対応させる。ファイル内ヘッダーが対応版Ankiでは自動設定する。
5. HTMLを有効にする。ファイルには `#html:true` が入っている。
6. プレビューでルビ・太字・改行を確認してから読み込む。

## 学習順を保つ

タグ付き版には `段階::小3`〜`段階::中3`、`段階::横断`、`優先度::A`〜`C` が入る。最初は未学習学年と優先度B・Cの新規カードを保留し、学習計画に合わせてAから解除すると負荷を調整しやすい。学校の進度が違う場合は、`単元::...` タグで必要な単元だけ先に学んでよい。

## 最小版

タグが不要なら `science_front_back.tsv` を使う。これは表・裏の2列だけで、全カードが一つの表として並ぶ。ファイル選択画面でTSVが見えにくい環境向けに、内容が同一の `science_front_back.txt` も収録している。

## CSV版

`science_front_back.csv` もAnki用ヘッダー付きで、そのまま読み込める。表計算ソフトで列名付きの表として開く用途には `science_front_back_with_header.csv` を使う。どちらもUTF-8。区切り文字が自動判定されない場合はカンマを選ぶ。

## 150枚から全体版へ移る

同じノートタイプへ全体版を読み込む。最初の150枚は表面が同一なので、Ankiの設定により既存ノートとして更新またはスキップされ、残り707枚が追加対象になる。読み込みプレビューで重複処理を確認する。

## 重複について

Ankiは通常、最初のフィールドで重複を判定する。この教材ではHTMLを除いた表面が重複しないよう検査している。同じノートタイプへ再読み込みすると、設定によって既存ノートを更新できる。
