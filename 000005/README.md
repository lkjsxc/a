# 小・中学校理科 体系フラッシュカード

日本の小学校3〜6年・中学校1〜3年の理科を、初学者が基礎から高校受験水準までつなげて学ぶための教材です。全857枚。表面は短い概念名、裏面は意味・仕組み・比較・実験・計算上の注意を必要に応じて含み、最後に複数の関連語を置いています。

## 設計方針

- 表面に「【物理】」などの接頭辞を付けず、想起の手掛かりを増やしすぎない。
- ルビは難読語に絞り、簡単な語へ過剰に振らない。
- 用語だけでなく、因果・比較・計算・実験・読図・誤解対策を独立して問う。
- 裏面から少なくとも三つの関連語を連想できるようにする。
- 現行の文部科学省学習指導要領に照らして小中の範囲を覆う。
