~~~text

Composition/framing: exactly 1536 x 1024 pixels, 3:2 landscape, calm hierarchy, generous whitespace, no outer border.
Color palette: indigo, teal, coral, and muted gold on warm off-white, with restrained subject-specific colors where scientifically useful.
Scientific constraints: classroom-appropriate and scientifically plausible; prose remains authoritative where scale or geometry is schematic.
Output constraints: exactly one opaque RGB PNG, no alpha and no tRNS.

~~~

通常上限は1アセット3回です。ユーザーが上限5回を明示的に許可した例外は、images/physics/overview.png、images/chemistry/states-of-matter.png、images/biology/photosynthesis-respiration.pngの3点だけです。これとは別に、2026-07-14に残ったimages/physics/forces.pngだけは試行回数制限を解除してcall 44を採用しました。call 35は中断して出力なし、call 45は未実行です。さらにユーザーの「細かいところには多少目をつむります」という指示により、対向矢印のピクセル単位の完全同一性だけを非ブロッキングとし、科学的正確性、原寸での見た目、接触、向き、視認上ほぼ等しいつり合いは維持しています。CLI生成器、変換ツール、SVG代用、追加依存、別モデル、手作業のラスタ修正は全26点で不使用です。

各項目のMust / Must notには共有条件に加える主題固有条件を記します。Visual QA: PASSは、プロジェクト内の採用PNGを原寸で確認した結果です。
