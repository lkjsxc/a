# よくある誤解の修正

間違いを避けるには、正しい文だけでなく「なぜ誤りか」を説明します。

| 表 | 裏 |
|---|---|
| 磁石につく物質 | 鉄・ニッケル・コバルトなどは磁石に強く引かれる。金属でもアルミニウムや銅はふつう磁石につかないため、「金属は全部つく」は誤り。**関連語：**鉄／磁力／金属 |
| 形を変えた物の重さ | 同じ物なら、丸める・伸ばす・置き方を変えるなど形を変えても重さは変わらない。ちぎれた一部を失ったり、別の物を加えたりすれば、その出入りの分だけ変わる。**関連語：**質量／保存／測定 |
| ショート回路 | 電池の＋極と−極を抵抗の小さい導線で直接つなぐ状態。非常に大きな電流が流れて導線や電池が発熱し、火災や破裂の危険がある。実験で行わない。**関連語：**電気抵抗／発熱／過電流 |
| <ruby>沸騰<rp>（</rp><rt>ふっとう</rt><rp>）</rp></ruby> | 液体内部からも気泡が生じ、液体全体で気化する現象。<ruby>沸点<rp>（</rp><rt>ふってん</rt><rp>）</rp></ruby>は物質と気圧で決まり、純物質では沸騰中の温度がほぼ一定。水中の気泡は空気とは限らず主に水蒸気。**関連語：**沸点／水蒸気／気圧 |
| 振り子の周期を変えない条件 | 小学校で扱う範囲では、振り子の長さが同じなら、おもりの重さを変えても周期は変わらない。振れ幅も極端に大きくなければ、周期への影響はほとんどないとして扱う。**関連語：**おもりの重さ／振れ幅／振り子の長さ |
| 溶ける | 物質の粒子が液体中へ均一に広がり、見えない大きさで混ざること。なくなったのではなく、溶液を蒸発させれば多くの場合取り出せる。沈んだだけ、融けただけとは異なる。**関連語：**溶解／水溶液／結晶 |
| 水溶液の均一性と透明性 | <ruby>溶質<rp>（</rp><rt>ようしつ</rt><rp>）</rp></ruby>が水中へ均一に広がり、どの部分も同じ濃さの透明な液体が水溶液。色があっても透明なものがあり、「無色」とは別。温度・水量が変わらず溶解度以内なら溶質だけが沈まない。**関連語：**均一／透明／溶質 |
| 原点を省いたグラフの注意 | 変化を拡大して見やすくできる一方、差が実際より大きく見えることがある。軸の開始値と途中の省略記号を確認し、棒の高さだけで差の割合を判断しない。**関連語：**原点／軸の省略／見かけの差／資料読解 |
| 原点を通る直線が示す関係 | 一方が2倍、3倍になると他方も2倍、3倍になる比例関係を示す。直線でも原点を通らなければ、単純な比例とはいえない。**関連語：**比例／原点／直線／比例定数 |
| 鏡で全身を見る条件 | 平面鏡で全身を見るのに必要な鏡の縦の長さは、目の位置によらず身長の1/2。頭頂と足先から目へ届く反射光を作図すると分かり、鏡から離れても必要な長さは変わらない。**関連語：**平面鏡／反射の作図／相似 |
| 音を伝える物質 | 音は空気・水・固体などの物質の振動として伝わる。真空には振動を受け渡す粒子がないので音は伝わらない。光は真空中も進むため混同しない。**関連語：**振動／真空／光 |
| 摩擦力 | 接触面で物体の相対的な動き、または動こうとする向きを妨げる力。必ず「進行方向と逆」とは限らず、歩くとき地面から足には前向きの摩擦力がはたらく。**関連語：**接触力／運動／仕事 |
| 垂直抗力 | 物体が面を押すとき、面から物体へ垂直に受ける力。水平面上で鉛直方向に他の力がなければ重力とつり合うが、斜面や外力があると大きさは重力と同じとは限らない。**関連語：**作用反作用／重力／摩擦力 |
| 接地面積と圧力 | 同じ物体なら面を変えて置いても重さは同じだが、接地面積が小さいほど圧力は大きい。面積が半分なら圧力は2倍。力自体が大きくなるわけではない。**関連語：**圧力／反比例／重力 |
| 浮力を決める量 | 同じ液体では、浮力は押しのけた液体の体積が大きいほど大きい。完全に水中へ沈めた同じ物体なら、深さを変えても浮力はほぼ変わらない。液体の密度も影響する。**関連語：**排除体積／密度／アルキメデスの原理 |
| 状態変化と質量 | 密閉した容器内では、状態が変わっても粒子の種類と数が同じなので全体の質量は変わらない。開放容器で液体が減るのは、気体となって外へ出たため。**関連語：**質量保存／蒸発／密閉系 |
| 有機物と無機物 | 中学では炭素を含む物質の多くを有機物とし、燃えると二酸化炭素を生じやすい。ただし黒鉛・ダイヤモンドなど炭素の単体、CO、CO₂、炭酸塩は無機物として扱う。**関連語：**炭素／燃焼／二酸化炭素 |
| マツの花と種子 | 雄花の花粉が風で雌花の<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>に届いて受粉する。雌花のりん片には胚珠がむき出しでつき、<ruby>子房<rp>（</rp><rt>しぼう</rt><rp>）</rp></ruby>がないため果実はできない。松かさは果実ではない。**関連語：**<ruby>裸子植物<rp>（</rp><rt>らししょくぶつ</rt><rp>）</rp></ruby>／雄花／雌花／胚珠 |
| 水中生活だけでは分類できない理由 | クジラは肺呼吸・恒温・胎生・授乳をするので哺乳類、ペンギンは羽毛と殻のある卵をもつ鳥類。生活場所ではなく、体のつくりや生殖の特徴で分類する。**関連語：**クジラ／ペンギン／形質／<ruby>脊椎動物<rp>（</rp><rt>せきついどうぶつ</rt><rp>）</rp></ruby> |
| 実験結果から言える範囲 | 実際に調べた対象・条件・数値範囲に限って結論を書く。少数の植物や一つの温度で得た結果を、全生物・全条件へ無条件に広げない。**関連語：**結論／一般化／標本／<ruby>外挿<rp>（</rp><rt>がいそう</rt><rp>）</rp></ruby> |
| 標本数が少ない資料の注意 | 偶然や個体差の影響を強く受け、全体の傾向を代表しにくい。対象を増やし、選び方の偏りを減らし、ばらつきも示すと信頼性が上がる。**関連語：**標本数／個体差／偏り／信頼性 |
| 欠けたデータを0として扱えない理由 | 未測定・測定失敗は「値が0」とは異なる。欠測の印を付け、理由を確認し、平均やグラフへ0として入れない。**関連語：**欠測値／ゼロ／平均／データ処理 |
| 相関だけで原因を決められない理由 | AがBを生むほか、BがAを生む、第三の要因が両方を変える、偶然という可能性がある。時間順序、仕組み、条件制御した実験などを追加して因果を検討する。**関連語：**相関／因果／<ruby>交絡要因<rp>（</rp><rt>こうらくよういん</rt><rp>）</rp></ruby>／対照実験 |
| 電流の向きと電子の向き | 電流の向きは回路の外部で＋極から−極へと定義する。金属中の自由電子は−極から＋極へ移動し、電流と逆向き。定義が電子発見より先に決まったためである。**関連語：**自由電子／電流／極性 |
| 直列回路の電流 | 分かれ道がないため、回路のどの点でも電流は等しい。I＝I₁＝I₂。各抵抗で電流が「使われて減る」のではなく、電気エネルギーが変換される。**関連語：**直列回路／電圧／電荷保存 |
| 直列・並列の合成抵抗の見分け | 直列は大きくなるので足し算、並列は通り道が増えるので最小の抵抗より小さくなる。この大小関係を使えば計算ミスを検出できる。**関連語：**直列回路／並列回路／合成抵抗 |
| 電流が流れない枝 | スイッチが開いている枝には閉じた経路がなく電流は0。導線で抵抗器を迂回する短絡路があると、理想的には抵抗器の両端電圧が0となり、ほぼ電流が流れない。**関連語：**開回路／短絡／電位差 |
| 元素 | 同じ種類の原子をひとまとめにした概念。物質を構成する原子の種類を表し、元素記号で示す。元素と単体は異なり、酸素元素は水にも含まれるが、酸素という単体はO₂。**関連語：**原子／元素記号／単体 |
| 分子をつくらない物質 | 塩化ナトリウムなどのイオン結晶、鉄・銅などの金属は独立した分子を作らず、多数の粒子が連続して並ぶ。化学式NaClやFeは粒子の種類・比を表す。**関連語：**イオン結晶／金属／化学式 |
| 元素記号の書き方 | 1文字目は大文字、2文字目があるときは小文字。Coはコバルト、COは炭素Cと酸素Oからなる一酸化炭素を表し意味が異なる。文字の大小を正確に書く。**関連語：**元素／化学式／原子 |
| 係数と右下の数字 | 2H₂Oの前の2は水分子2個を表し、式全体にかかるためH原子4個・O原子2個。H₂O₂の右下数字は1分子の組成を変える。係数は変えてよいが右下数字は変えない。**関連語：**化学反応式／原子数／化学式 |
| <ruby>触媒<rp>（</rp><rt>しょくばい</rt><rp>）</rp></ruby> | 反応の前後で自身はほぼ変化せず、反応速度を変える物質。二酸化マンガンは過酸化水素の分解を速めるが、できる酸素の最終総量は増やさない。少量でも働く。**関連語：**反応速度／二酸化マンガン／過酸化水素 |
| 吸熱反応 | 化学変化が周囲から熱を吸収し、周囲の温度が下がる反応。例として塩化アンモニウムと水酸化バリウムの反応など。単なる氷の<ruby>融解<rp>（</rp><rt>ゆうかい</rt><rp>）</rp></ruby>は吸熱だが化学反応ではなく状態変化。**関連語：**温度低下／状態変化／化学エネルギー |
| 開放容器で質量が変わる理由 | 気体が外へ逃げる反応では容器内の測定質量が減り、空気中の酸素を取り込む反応では増える。容器と出入りした気体まで含めれば全体の質量は保存される。**関連語：**質量保存／気体／酸化 |
| 植物の呼吸 | 植物も昼夜を通して、細胞で有機物と酸素を使い、二酸化炭素と水を生じながらエネルギーを取り出す。昼は光合成量が呼吸量を上回りやすく、見かけ上は二酸化炭素を吸収する。**関連語：**細胞呼吸／光合成／酸素／二酸化炭素 |
| <ruby>胆汁<rp>（</rp><rt>たんじゅう</rt><rp>）</rp></ruby>のはたらき | 肝臓でつくられ胆のうに蓄えられ、小腸へ出る。脂肪を細かい粒にして水と混ざりやすくし、リパーゼの作用を助けるが、胆汁自体には<ruby>消化酵素<rp>（</rp><rt>しょうかこうそ</rt><rp>）</rp></ruby>を含まない。**関連語：**肝臓／胆のう／脂肪／リパーゼ |
| 雲ができる基本 | 空気中の水蒸気が冷やされ、細かな水滴や氷の粒になって空中に浮かぶと雲になる。水蒸気そのものは目に見えず、白く見える湯気も細かな水滴である。**関連語：**水蒸気／<ruby>凝結<rp>（</rp><rt>ぎょうけつ</rt><rp>）</rp></ruby>／水滴／気温 |
| 降水確率の意味 | 予報区内で一定時間内に1 mm以上の雨または雪が降る確率の平均値で、0、10、…、100%の10%刻みで発表される。30%予報を同じ条件で100回出せば約30回で1 mm以上となる意味で、雨の強さ・量・継続時間や区域の30%に降ることを示さない。**関連語：**天気予報／降水量／確率／予報区 |
| 冷えた容器の外側に付く水滴 | 周囲の空気が容器表面で露点以下に冷え、空気中の水蒸気が<ruby>凝結<rp>（</rp><rt>ぎょうけつ</rt><rp>）</rp></ruby>してできたもの。容器内の水が壁を染み出したのではない。外面を事前に乾かし、冷やさない対照と比べると由来を確かめやすい。**関連語：**水蒸気／<ruby>露点<rp>（</rp><rt>ろてん</rt><rp>）</rp></ruby>／凝結／対照実験 |
| 模型から言えることの限界 | 模型は注目する構造・関係を単純化して表す。粒子の色や天体間距離など、説明のために変えた部分を現実そのものと思わず、何を表し何を省いたか明示する。**関連語：**模型／単純化／粒子モデル／天体モデル |
| 運動の基準点 | 物体が動いているかどうかは、どの物体を基準にするかで変わる。電車内で座る人は車内には静止、地面には運動している。位置は基準点からの向きと距離で表す。**関連語：**相対運動／位置／速度 |
| 自由落下 | 空気抵抗を無視し、重力だけで落ちる運動。落下中は下向きの速さが一定の割合で増える。重い物体ほど速く落ちるのではなく、同じ場所なら加速の割合は同じ。**関連語：**重力／加速／空気抵抗 |
| 作用・反作用 | 物体AがBに力を及ぼすと、同時にBもAへ大きさが等しく向きが反対の力を及ぼす。2力は別々の物体にはたらくため、同一物体上の力のつり合いではない。**関連語：**力のつり合い／垂直抗力／反作用 |
| 力と速さの変化 | 運動方向と同じ向きに合力があれば速くなり、反対向きなら遅くなる。合力が0なら速さは変わらない。一定の力があると「一定の速さ」ではなく「一定の割合で速さが変化」する。**関連語：**合力／加速／<ruby>慣性<rp>（</rp><rt>かんせい</rt><rp>）</rp></ruby> |
| 仕事が0になる場合 | 力を加えても物体が動かない場合、または力と移動方向が垂直な場合、その力のした仕事は0。荷物を水平に運ぶとき、支える上向きの力の仕事は0。疲労とは別の物理量。**関連語：**仕事／移動距離／力の向き |
| 摩擦があるときのエネルギー | 力学的エネルギーの一部が熱や音などへ変換されるため、力学的エネルギーは減る。しかし熱なども含めた全エネルギーは保存される。「エネルギーが消えた」わけではない。**関連語：**摩擦／熱／エネルギー保存 |
| 原子がイオンになるときの電子 | ナトリウム原子は電子1個を失いNa⁺、塩素原子は電子1個を受け取りCl⁻。イオンになるのは電子の出入りであり、陽子や中性子が移動するのではない。**関連語：**Na+／Cl-／電子移動 |
| 塩（化学） | 酸の陰イオンとアルカリの陽イオンなどからできる物質。塩酸と水酸化ナトリウムでは塩化ナトリウム、硫酸と水酸化バリウムでは硫酸バリウムができる。「食塩」だけを指さない。**関連語：**中和／塩化ナトリウム／硫酸バリウム |
| 中和と中性の違い | 中和はH⁺とOH⁻が反応する現象で、途中でも起こる。中性はH⁺とOH⁻が過不足なくなった状態。酸やアルカリが余れば、中和が起きていても液は酸性またはアルカリ性。**関連語：**過不足／pH／中和点 |
| 電気分解の陰極 | 電源の−極につながる電極。陽イオンが引かれ、電子を受け取る。塩化銅水溶液ではCu²⁺＋2e⁻→Cuとなり銅が<ruby>析出<rp>（</rp><rt>せきしゅつ</rt><rp>）</rp></ruby>する。「陰極＝陰イオンが来る」は誤り。**関連語：**陽イオン／電子／銅析出 |
| 電池内の電子と電流の向き | 外部回路の電子は−極から＋極へ流れ、電流の向きはその逆で＋極から−極。電解質中ではイオンが移動して電荷の偏りを防ぎ、回路を成立させる。**関連語：**電子／電流／イオン移動 |
| ダニエル電池の電子と電流 | 外部回路の電子は亜鉛極（−）から銅極（＋）へ流れ、電流の向きは逆に銅極から亜鉛極。溶液中を電子が横切るのではなく、イオンが動く。**関連語：**電子の向き／電流の向き／イオン移動 |
| 進化 | 生物の集団の遺伝的な性質が、長い世代を通して変化すること。個体が必要に応じて一生の間に変身することではない。化石・相同器官・DNAの比較などが証拠になる。**関連語：**遺伝／自然選択／化石／相同器官 |
| 種子の中の<ruby>胚<rp>（</rp><rt>はい</rt><rp>）</rp></ruby> | 受精卵が分裂してできる次世代の植物体で、幼根・幼芽・<ruby>子葉<rp>（</rp><rt>しよう</rt><rp>）</rp></ruby>などを含む。<ruby>子房<rp>（</rp><rt>しぼう</rt><rp>）</rp></ruby>は果実、<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>は種子になるが、受精卵そのものが種子全体になるわけではない。**関連語：**受精卵／胚珠／種子／子葉 |
| <ruby>顕性形質<rp>（</rp><rt>けんせいけいしつ</rt><rp>）</rp></ruby>と<ruby>潜性形質<rp>（</rp><rt>せんせいけいしつ</rt><rp>）</rp></ruby> | 対立遺伝子を1つずつもつ個体で現れる形質を<ruby>顕性<rp>（</rp><rt>けんせい</rt><rp>）</rp></ruby>、現れない方を<ruby>潜性<rp>（</rp><rt>せんせい</rt><rp>）</rp></ruby>という。旧称は優性・劣性。生存上『優れている・劣っている』という意味ではない。**関連語：**対立遺伝子／遺伝子型／表現型／メンデル |
| 遺伝の確率問題 | 各子がある形質になる確率は、通常それぞれ独立に考える。確率1/4だから4匹産まれれば必ず1匹という意味ではない。配偶子の組み合わせ表を作ると整理しやすい。**関連語：**確率／分離の法則／配偶子／組み合わせ表 |
| 季節が生じる理由 | 地軸が公転面に垂直な方向から傾いたまま地球が公転するため、太陽の南中高度と昼の長さが季節で変わり、単位面積が受ける日射量が変化する。太陽との距離変化が主因ではない。**関連語：**地軸の傾き／南中高度／昼の長さ／日射量 |
| 月の自転と公転 | 月は星空に対して約27.3日で地球を公転し、自転周期もほぼ同じため、地球にはほぼ同じ面を向け続ける。地球も太陽の周りを進むので、満ち欠けが同じ形へ戻る周期は約29.5日。月が自転していないなら、公転中に違う面が見えるはずである。**関連語：**同期回転／公転周期／満ち欠け／月の裏側 |
| 五感を使う観察の限界 | 色・音・手触りなどは手掛かりになるが、未知の物を味見したり直接かいだり、熱い物へ触れたりしてはいけない。安全でない感覚は器具による測定へ置き換える。**関連語：**観察／測定器具／安全／気体 |
| 平均だけで結果を判断できない場合 | 平均が同じでも、値の散らばりや外れ値が大きく違う場合がある。元の値、範囲、測定回数も見て、結果が安定しているか判断する。**関連語：**平均／散らばり／外れ値／信頼性 |
| 温度と熱の違い | 温度は物体の熱さ・冷たさの程度、熱は温度差によって移動するエネルギー。同じ基準温度まで冷やすなら、少量の熱湯より大量のぬるま湯のほうが多くのエネルギーを放出することもある。**関連語：**熱量／比熱／熱平衡 |
