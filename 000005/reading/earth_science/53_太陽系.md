| 太陽系の<ruby>惑星<rt>わくせい</rt></ruby>の順序 | 太陽に近い順に水星・金星・地球・火星・木星・土星・天王星・海王星。<ruby>惑星<rt>わくせい</rt></ruby>は太陽の周りをほぼ同一平面上で同じ向きに公転する。冥王星は準惑星。**つながり：**水星／地球型惑星／木星型惑星／準惑星 |
| 地球型<ruby>惑星<rt>わくせい</rt></ruby>と木星型惑星 | 地球型は水星・金星・地球・火星で、小さく高密度の岩石質。木星型は木星・土星・天王星・海王星で、大きく低密度、厚い大気と多くの<ruby>衛星<rt>えいせい</rt></ruby>・環をもつ。**つながり：**岩石質／密度／衛星／環 |
| <ruby>恒星<rt>こうせい</rt></ruby>・<ruby>惑星<rt>わくせい</rt></ruby>・<ruby>衛星<rt>えいせい</rt></ruby> | <ruby>恒星<rt>こうせい</rt></ruby>は自ら光を放つ天体、<ruby>惑星<rt>わくせい</rt></ruby>は恒星の周りを回り主に<ruby>反射<rt>はんしゃ</rt></ruby>光で見える天体、<ruby>衛星<rt>えいせい</rt></ruby>は惑星などの周りを回る天体。太陽は恒星、地球は惑星、月は衛星。**つながり：**恒星／惑星／衛星／太陽 |
| 小<ruby>惑星<rt>わくせい</rt></ruby>・<ruby>彗星<rt>すいせい</rt></ruby>・流星 | 小<ruby>惑星<rt>わくせい</rt></ruby>は主に火星と木星の間などを公転する小天体。彗星は氷やちりを含み、太陽に近づくと尾を生じ、尾は太陽と反対向き。流星は小粒子が大気中で発光する現象。**つながり：**小惑星帯／彗星／流星体／太陽風 |
