## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| <ruby>飽和水蒸気量<rt>ほうわすいじょうきりょう</rt></ruby> | 1 m³の空気がある温度で含むことのできる水蒸気の最大質量。気温が高いほど大きい。『現在含まれる量』ではなく上限なので、気温が変われば値も変わる。**つながり：**水蒸気／湿度／<ruby>露点<rt>ろてん</rt></ruby>／<ruby>凝結<rt>ぎょうけつ</rt></ruby> |
| 相対湿度の計算 | 湿度(%)＝実際の水蒸気量÷その気温での<ruby>飽和水蒸気量<rt>ほうわすいじょうきりょう</rt></ruby>×100。同じ水蒸気量でも気温が下がると飽和水蒸気量が減るため、湿度は上がる。単位をそろえる。**つながり：**飽和水蒸気量／水蒸気量／気温／<ruby>露点<rt>ろてん</rt></ruby> |
| <ruby>露点<rt>ろてん</rt></ruby> | 空気を水蒸気量を変えずに冷やしたとき、湿度が100%になり<ruby>凝結<rt>ぎょうけつ</rt></ruby>が始まる温度。<ruby>露点<rt>ろてん</rt></ruby>が高いほど、その空気に実際に含まれる水蒸気量が多い。現在の気温とは別。**つながり：**凝結／飽和／湿度／水蒸気量 |
| <ruby>露点<rt>ろてん</rt></ruby>から水蒸気量を求める | 空気中の実際の水蒸気量は、<ruby>露点<rt>ろてん</rt></ruby>における<ruby>飽和水蒸気量<rt>ほうわすいじょうきりょう</rt></ruby>に等しい。まず表・グラフで露点の飽和値を読み、その値を現在気温の飽和値で割れば湿度が求まる。**つながり：**露点／飽和水蒸気量曲線／湿度／<ruby>凝結<rt>ぎょうけつ</rt></ruby> |
| 空気を冷やしたときに<ruby>凝結<rt>ぎょうけつ</rt></ruby>する水の量 | <ruby>露点<rt>ろてん</rt></ruby>より低い温度まで冷やすと、<ruby>凝結<rt>ぎょうけつ</rt></ruby>量＝もとの実際の水蒸気量－冷却後の<ruby>飽和水蒸気量<rt>ほうわすいじょうきりょう</rt></ruby>。体積が指定される場合は1 m³あたりの差に体積を掛ける。**つながり：**凝結量／露点／飽和水蒸気量／体積 |
| <ruby>乾湿計<rt>かんしつけい</rt></ruby> | 乾球温度計と、ぬれた布を巻いた湿球温度計を用いる。湿球の布を十分ぬらし、通風させて示度が安定してから両方を読む。蒸発で湿球が冷えるため、空気が乾くほど乾球との差が大きく、湿度100%ではほぼ同じ温度になる。**つながり：**乾球温度／湿球温度／蒸発／湿度表 |
| <ruby>露点<rt>ろてん</rt></ruby>を測る金属容器の実験 | 磨いた金属容器に水と温度計を入れ、かき混ぜながら氷水を少しずつ加える。容器の外側が曇り始めた瞬間の水温を、その空気の<ruby>露点<rt>ろてん</rt></ruby>とみなす。金属は熱を伝えやすく、容器表面と中の水の温度がほぼ等しくなることを利用する。**つながり：**露点／<ruby>凝結<rt>ぎょうけつ</rt></ruby>／水蒸気／湿度 |
| 冷えた容器の外側に付く水滴 | 周囲の空気が容器表面で<ruby>露点<rt>ろてん</rt></ruby>以下に冷え、空気中の水蒸気が<ruby>凝結<rt>ぎょうけつ</rt></ruby>してできたもの。容器内の水が壁を染み出したのではない。外面を事前に乾かし、冷やさない対照と比べると由来を確かめやすい。**つながり：**水蒸気／露点／凝結／<ruby>対照実験<rt>たいしょうじっけん</rt></ruby> |
| 乾湿計の湿度表の読み方 | ①乾球温度と湿球温度を読む、②乾球温度−湿球温度を求める、③湿度表の乾球温度の行と温度差の列の交点を読む。例として乾球20℃・湿球16℃なら温度差4℃の欄を使う。表によって行列が逆の場合は見出しを確認し、両温度が同じなら湿度は100%である。**つながり：**乾球温度／湿球温度／温度差／相対湿度 |
