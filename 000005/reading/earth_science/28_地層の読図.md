# 地層の読図

## この単元でつかむこと

- <ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby>
- 鍵層
- <ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby>から地層の傾きを読む
- ボーリング資料の標高換算
- 地質断面の出来事の順序

## カード構成

5枚（読図3・用語1・計算1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| <ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby> | ある地点の地層を、厚さ・岩質・化石などとともに柱状に表した図。上ほど新しいのが基本。標高の異なる地点を比べるときは、図の上端ではなく同じ標高や鍵層を基準にする。**関連語：**地層／標高／鍵層／地層対比 |
| 鍵層 | 特徴が明瞭で広く追跡でき、複数地点の地層を対比する目印となる層。短時間に広域へ積もった火山灰層などが適する。同じ岩質というだけで同一層とは限らない。**関連語：**火山灰層／<ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby>／地層対比／噴火 |
| <ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby>から地層の傾きを読む | 同じ鍵層の標高を比べると、2地点を結ぶ方向では高い側から低い側へ地層が傾く。地表高度と鍵層までの深さから実際の標高を求める。真の傾斜方向や走向を一意に定めるには、一直線上でない少なくとも3地点が必要。**関連語：**鍵層／標高／深さ／走向傾斜 |
| ボーリング資料の標高換算 | 地層境界の標高＝地表の標高－地表からの深さ。複数地点で同じ層の境界標高を比較する。深さの数値だけを直接比べると、地表の高さが違う場合に誤る。**関連語：**ボーリング／<ruby>柱状図<rp>（</rp><rt>ちゅうじょうず</rt><rp>）</rp></ruby>／標高／鍵層 |
| 地質断面の出来事の順序 | 基本は<ruby>堆積<rp>（</rp><rt>たいせき</rt><rp>）</rp></ruby>→変形や<ruby>貫入<rp>（</rp><rt>かんにゅう</rt><rp>）</rp></ruby>→<ruby>侵食<rp>（</rp><rt>しんしょく</rt><rp>）</rp></ruby>→新たな堆積。断層や火成岩が切っている地層より、その断層・貫入は新しい。切られている方が古いという交差関係を使う。**関連語：**断層／貫入／<ruby>不整合<rp>（</rp><rt>ふせいごう</rt><rp>）</rp></ruby>／新旧関係 |
