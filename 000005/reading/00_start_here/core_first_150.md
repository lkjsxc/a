# 最初の150枚

857枚を最初から同じ重みで学ばず、まず説明力の高い150枚で全体の骨格をつくります。用語の知名度だけでなく、別の現象を説明できる因果・比較・実験・計算を優先し、同義のまとめカードは避けています。

## 進め方

1. 1日15〜20枚、8〜10日で一巡する。
2. 表を見て、裏面の第一文に相当する説明を声に出す。
3. 「つながり」から一語を選び、表の概念との関係を一文で言う。
4. 一巡後は `science_tagged.tsv` の優先度Aへ進み、コアカードも間隔反復で残す。

## 判定

用語だけ言えた場合は正解にしません。意味、原因または比較、代表例のうち二つを説明できれば正解とします。計算・実験カードは式や操作の理由まで再現します。
