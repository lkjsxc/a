## 読み進め方

| 表 | 裏 |
|---|---|
| 背骨の有無による分類 | 背骨をもつ動物を<ruby>脊椎動物<rt>せきついどうぶつ</rt></ruby>、もたない動物を<ruby>無脊椎動物<rt>むせきついどうぶつ</rt></ruby>という。体の大小や陸上・水中という生活場所ではなく、体のつくりに基づく分類である。**つながり：**脊椎動物／無脊椎動物／分類／背骨 |
| <ruby>脊椎動物<rt>せきついどうぶつ</rt></ruby>の5群 | 魚類・両生類・<ruby>爬虫類<rt>はちゅうるい</rt></ruby>・鳥類・哺乳類に分ける。呼吸器官、体表、体温、<ruby>受精<rt>じゅせい</rt></ruby>・子の生まれ方などを組み合わせて判断する。**つながり：**魚類／両生類／爬虫類／鳥類／哺乳類 |
| 動物を分類する観点 | 背骨の有無を大きな基準とし、<ruby>脊椎動物<rt>せきついどうぶつ</rt></ruby>では呼吸器官・体表・体温・<ruby>受精<rt>じゅせい</rt></ruby>場所・子の生まれ方を比べる。見た目や生活場所だけで決めず、複数の形質を組み合わせる。**つながり：**脊椎動物／<ruby>無脊椎動物<rt>むせきついどうぶつ</rt></ruby>／形質／分類 |
| 魚類の特徴 | 一生を主に水中で過ごし、えらで呼吸し、ひれで泳ぐ。体表はうろこで覆われるものが多く、変温動物。多くは殻のない卵を水中に産み体外<ruby>受精<rt>じゅせい</rt></ruby>する。**つながり：**えら／うろこ／変温動物／体外受精 |
| 両生類の特徴 | 幼生は水中でえら呼吸し、成体は肺と皮膚で呼吸する。湿った皮膚をもち変温動物で、多くは殻のない卵を水中に産み体外<ruby>受精<rt>じゅせい</rt></ruby>する。カエルやイモリが代表。**つながり：**えら呼吸／肺呼吸／変態／体外受精 |
| <ruby>爬虫類<rt>はちゅうるい</rt></ruby>の特徴 | 一生を肺で呼吸し、乾燥を防ぐうろこや甲で体表が覆われた変温動物。多くは陸上に殻のある卵を産み体内<ruby>受精<rt>じゅせい</rt></ruby>する。カメ・トカゲ・ヘビ・ワニが代表。**つながり：**肺呼吸／うろこ／変温動物／体内受精 |
| 鳥類の特徴 | 肺で呼吸し、体表は羽毛で覆われ、体温をほぼ一定に保つ恒温動物。殻のある卵を産み体内<ruby>受精<rt>じゅせい</rt></ruby>する。飛べないペンギンやダチョウも鳥類である。**つながり：**羽毛／恒温動物／卵生／体内受精 |
| 哺乳類の特徴 | 肺で呼吸し、体表に毛があり、恒温動物。多くは母体内で育った子を産み、乳で育てる。カモノハシは卵生、クジラは水中生活だが哺乳類である。**つながり：**体毛／恒温動物／胎生／乳 |
| 恒温動物と変温動物 | 恒温動物は外気温が変わっても体温をほぼ一定に保つ鳥類・哺乳類。変温動物は周囲の温度に伴って体温が変わりやすい魚類・両生類・爬虫類。『血が温かいか冷たいか』という分類ではない。**つながり：**鳥類／哺乳類／代謝／体温 |
| 体外<ruby>受精<rt>じゅせい</rt></ruby>と体内受精 | 体外<ruby>受精<rt>じゅせい</rt></ruby>は雌雄が体外へ出した卵と精子が受精し、魚類・両生類に多い。体内受精は雌の体内で受精し、爬虫類・鳥類・哺乳類に多い。産卵か胎生かとは別の観点である。**つながり：**受精／卵生／胎生／生殖 |
| 卵生と胎生 | 卵生は母体外に産まれた卵の中で発生し、胎生は母体内である程度育ってから子として生まれる。<ruby>受精<rt>じゅせい</rt></ruby>場所とは別で、鳥類は体内受精だが卵生、哺乳類の多くは体内受精で胎生。**つながり：**体内受精／発生／鳥類／哺乳類 |
| 水中生活だけでは分類できない理由 | クジラは肺呼吸・恒温・胎生・授乳をするので哺乳類、ペンギンは羽毛と殻のある卵をもつ鳥類。生活場所ではなく、体のつくりや生殖の特徴で分類する。**つながり：**クジラ／ペンギン／形質／<ruby>脊椎動物<rt>せきついどうぶつ</rt></ruby> |
