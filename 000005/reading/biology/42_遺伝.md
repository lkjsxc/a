| 表 | 裏 |
|---|---|
| <ruby>遺伝<rt>いでん</rt></ruby>と形質 | 親の形質が子へ伝わる現象が<ruby>遺伝<rt>いでん</rt></ruby>。生物の形や性質の特徴を形質という。形質は遺伝子だけでなく環境の影響も受けるため、同じ遺伝情報でも完全に同じになるとは限らない。**つながり：**形質／遺伝子／環境／DNA |
| 対立形質 | 同じ形質について、区別して比べる対になる現れ方。エンドウの種子の形が丸かしわか、など。単に反対語なら何でも対立形質というわけではない。後続の3:1などの比は、一方だけが現れる完全<ruby>顕性<rt>けんせい</rt></ruby>を仮定する。**つながり：**形質／優性形質／劣性形質／エンドウ |
| <ruby>顕性形質<rt>けんせいけいしつ</rt></ruby>と<ruby>潜性形質<rt>せんせいけいしつ</rt></ruby> | 対立<ruby>遺伝<rt>いでん</rt></ruby>子を1つずつもつ個体で現れる形質を<ruby>顕性<rt>けんせい</rt></ruby>、現れない方を<ruby>潜性<rt>せんせい</rt></ruby>という。旧称は優性・劣性。生存上『優れている・劣っている』という意味ではない。**つながり：**対立遺伝子／遺伝子型／表現型／メンデル |
| 純系 | 自家<ruby>受精<rt>じゅせい</rt></ruby>などを何代繰り返しても同じ形質の子だけを生じる系統。ある形質について同じ対立<ruby>遺伝<rt>いでん</rt></ruby>子を2つもつ。メンデルは純系どうしを交配して規則性を調べた。**つながり：**自家受精／対立遺伝子／メンデル／交配 |
| 分離の法則 | 対になっている対立<ruby>遺伝<rt>いでん</rt></ruby>子は、生殖細胞ができるときに分かれ、各生殖細胞には一方だけが入る。<ruby>受精<rt>じゅせい</rt></ruby>で再び対になる。子の比を求める土台。**つながり：**対立遺伝子／生殖細胞／受精／遺伝子型 |
| 一<ruby>遺伝<rt>いでん</rt></ruby>子雑種のF1 | 純系AAと純系aaを交配すると、F1はすべてAaとなり<ruby>顕性形質<rt>けんせいけいしつ</rt></ruby>を示す。『<ruby>顕性<rt>けんせい</rt></ruby><ruby>遺伝<rt>いでん</rt></ruby>子だけを受け継ぐ』のではなく、<ruby>潜性<rt>せんせい</rt></ruby>のaももっている。**つながり：**純系／F1／顕性形質／遺伝子型 |
| F2の<ruby>遺伝<rt>いでん</rt></ruby>子型と表現型の比 | F1どうしAa×Aaでは、<ruby>遺伝<rt>いでん</rt></ruby>子型AA:Aa:aa＝1:2:1、完全<ruby>顕性<rt>けんせい</rt></ruby>なら表現型は顕性:<ruby>潜性<rt>せんせい</rt></ruby>＝3:1。個体数が少ない実験では実測値が厳密な比からずれる。**つながり：**F2／遺伝子型／表現型／分離の法則 |
| <ruby>検定交雑<rt>けんていこうざつ</rt></ruby>の考え方 | <ruby>顕性形質<rt>けんせいけいしつ</rt></ruby>の個体がAAかAaか調べるには、<ruby>潜性<rt>せんせい</rt></ruby>のaaと交配する。子に<ruby>潜性形質<rt>せんせいけいしつ</rt></ruby>が現れれば親はAa。すべて<ruby>顕性<rt>けんせい</rt></ruby>でも、子の数が少ない場合はAAと断定しきれない。**つながり：**顕性形質／潜性形質／<ruby>遺伝<rt>いでん</rt></ruby>子型／交配 |
| <ruby>遺伝<rt>いでん</rt></ruby>の確率問題 | 各子がある形質になる確率は、通常それぞれ独立に考える。確率1/4だから4匹産まれれば必ず1匹という意味ではない。配偶子の組み合わせ表を作ると整理しやすい。**つながり：**確率／分離の法則／配偶子／組み合わせ表 |
| <ruby>有性生殖<rt>ゆうせいせいしょく</rt></ruby>が多様性を生む理由 | 両親由来の<ruby>遺伝<rt>いでん</rt></ruby>子が生殖細胞形成と<ruby>受精<rt>じゅせい</rt></ruby>で組み合わされ、子ごとに異なる組み合わせが生じるため。環境変化に強い個体を含む可能性が増え、集団の存続に有利になりうる。**つながり：**<ruby>有性生殖<rt>ゆうせいせいしょく</rt></ruby>／遺伝的多様性／受精／自然選択 |
