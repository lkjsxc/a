## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 根毛 | 根の先端近くの表皮細胞が細長く伸びたもの。土粒のすき間に入り、根の表面積を大きくして水と無機養分を吸収しやすくする。細い根そのものとは区別する。**つながり：**根／吸水／表面積／無機養分 |
| <ruby>道管<rt>どうかん</rt></ruby> | 根から吸収した水と無機養分を主に上向きに運ぶ管。茎の<ruby>維管束<rt>いかんそく</rt></ruby>内では、<ruby>双子葉類<rt>そうしようるい</rt></ruby>なら一般に内側、葉では葉脈に含まれる。古い細胞が管状につながっている。**つながり：**<ruby>師管<rt>しかん</rt></ruby>／維管束／<ruby>蒸散<rt>じょうさん</rt></ruby>／吸水 |
| <ruby>師管<rt>しかん</rt></ruby> | 葉でつくられた糖などの有機物を、成長部や根・果実など必要な場所へ運ぶ管。運ばれる向きは必要部位により変わり、常に下向きとは限らない。**つながり：**<ruby>道管<rt>どうかん</rt></ruby>／<ruby>維管束<rt>いかんそく</rt></ruby>／光合成／転流 |
| <ruby>維管束<rt>いかんそく</rt></ruby> | <ruby>道管<rt>どうかん</rt></ruby>と<ruby>師管<rt>しかん</rt></ruby>がまとまった束。<ruby>双子葉類<rt>そうしようるい</rt></ruby>の茎では輪状、<ruby>単子葉類<rt>たんしようるい</rt></ruby>の茎では散らばって並ぶ。根・茎・葉を連続してつなぎ、水や養分を運ぶ。**つながり：**道管／師管／双子葉類／単子葉類 |
| 茎の<ruby>維管束<rt>いかんそく</rt></ruby>の並び方 | <ruby>双子葉類<rt>そうしようるい</rt></ruby>では<ruby>維管束<rt>いかんそく</rt></ruby>が輪状に並び、各束の内側が<ruby>道管<rt>どうかん</rt></ruby>、外側が<ruby>師管<rt>しかん</rt></ruby>。<ruby>単子葉類<rt>たんしようるい</rt></ruby>では維管束が全体に散らばる。断面図では根や葉との向きを混同しない。**つながり：**維管束／道管／師管／茎の断面 |
| 葉の断面 | 表側と裏側を表皮が覆い、内部の葉肉細胞に葉緑体が多い。葉脈には<ruby>道管<rt>どうかん</rt></ruby>と<ruby>師管<rt>しかん</rt></ruby>が通り、表皮、とくに裏側には<ruby>気孔<rt>きこう</rt></ruby>が多い植物が一般的。**つながり：**表皮／葉肉／葉脈／気孔 |
| <ruby>気孔<rt>きこう</rt></ruby>と<ruby>孔辺細胞<rt>こうへんさいぼう</rt></ruby> | <ruby>気孔<rt>きこう</rt></ruby>は2個の孔辺細胞に囲まれたすき間で、二<ruby>酸化<rt>さんか</rt></ruby>炭素・酸素・水蒸気が出入りする。孔辺細胞の開閉によって<ruby>蒸散<rt>じょうさん</rt></ruby>と気体交換が調節される。**つながり：**孔辺細胞／蒸散／気体交換／二酸化炭素 |
