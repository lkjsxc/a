## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 根毛 | 根の先端近くの表皮細胞が細長く伸びたもの。土粒のすき間に入り、根の表面積を大きくして水と無機養分を吸収しやすくする。細い根そのものとは区別する。**関連語：**根／吸水／表面積／無機養分 |
| 道管 | 根から吸収した水と無機養分を主に上向きに運ぶ管。茎の維管束内では、<ruby>双子葉類<rp>（</rp><rt>そうしようるい</rt><rp>）</rp></ruby>なら一般に内側、葉では葉脈に含まれる。古い細胞が管状につながっている。**関連語：**<ruby>師管<rp>（</rp><rt>しかん</rt><rp>）</rp></ruby>／<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>／<ruby>蒸散<rp>（</rp><rt>じょうさん</rt><rp>）</rp></ruby>／吸水 |
| <ruby>師管<rp>（</rp><rt>しかん</rt><rp>）</rp></ruby> | 葉でつくられた糖などの有機物を、成長部や根・果実など必要な場所へ運ぶ管。運ばれる向きは必要部位により変わり、常に下向きとは限らない。**関連語：**道管／<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>／光合成／転流 |
| <ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby> | 道管と<ruby>師管<rp>（</rp><rt>しかん</rt><rp>）</rp></ruby>がまとまった束。<ruby>双子葉類<rp>（</rp><rt>そうしようるい</rt><rp>）</rp></ruby>の茎では輪状、<ruby>単子葉類<rp>（</rp><rt>たんしようるい</rt><rp>）</rp></ruby>の茎では散らばって並ぶ。根・茎・葉を連続してつなぎ、水や養分を運ぶ。**関連語：**道管／師管／双子葉類／単子葉類 |
| 茎の<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>の並び方 | <ruby>双子葉類<rp>（</rp><rt>そうしようるい</rt><rp>）</rp></ruby>では維管束が輪状に並び、各束の内側が道管、外側が<ruby>師管<rp>（</rp><rt>しかん</rt><rp>）</rp></ruby>。<ruby>単子葉類<rp>（</rp><rt>たんしようるい</rt><rp>）</rp></ruby>では維管束が全体に散らばる。断面図では根や葉との向きを混同しない。**関連語：**維管束／道管／師管／茎の断面 |
| 葉の断面 | 表側と裏側を表皮が覆い、内部の葉肉細胞に葉緑体が多い。葉脈には道管と<ruby>師管<rp>（</rp><rt>しかん</rt><rp>）</rp></ruby>が通り、表皮、とくに裏側には<ruby>気孔<rp>（</rp><rt>きこう</rt><rp>）</rp></ruby>が多い植物が一般的。**関連語：**表皮／葉肉／葉脈／気孔 |
| <ruby>気孔<rp>（</rp><rt>きこう</rt><rp>）</rp></ruby>と<ruby>孔辺細胞<rp>（</rp><rt>こうへんさいぼう</rt><rp>）</rp></ruby> | 気孔は2個の孔辺細胞に囲まれたすき間で、二酸化炭素・酸素・水蒸気が出入りする。孔辺細胞の開閉によって<ruby>蒸散<rp>（</rp><rt>じょうさん</rt><rp>）</rp></ruby>と気体交換が調節される。**関連語：**孔辺細胞／蒸散／気体交換／二酸化炭素 |
