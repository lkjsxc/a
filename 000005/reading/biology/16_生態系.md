## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 食べる・食べられる関係 | 野外で動物が何を食べるかを観察すると、植物→草食動物→肉食動物のように、生物どうしが食べる・食べられる関係でつながっていると分かる。一つの生物は複数の相手と関わるので、実際のつながりは網のように広がる。**関連語：**食物連鎖／食物網／生産者／消費者 |
| 落ち葉や死がいが減っていく理由 | 落ち葉や死がいは、土の中の小動物に細かくされ、菌類や細菌類などの微生物に分解されるため、しだいに形が見えなくなる。分解された物質の一部は植物に再利用される。**関連語：**分解者／菌類／細菌類／物質循環 |
| 生態系 | ある地域の生物群集と、それを取り巻く光・水・空気・土などの非生物的環境を一つのまとまりとして捉えたもの。生物だけを指す語ではない。**関連語：**生物群集／環境／食物網／物質循環 |
| 生産者 | 光合成によって無機物から有機物をつくる生物。陸上の植物や水中の植物プランクトンなど。食物連鎖のエネルギーの入口になる。**関連語：**光合成／植物／有機物／消費者 |
| 消費者 | 他の生物やその一部を食べて有機物を得る生物。草食・肉食・雑食動物などを含む。『消費者＝肉食動物』ではなく、生産者を食べる一次消費者もいる。**関連語：**生産者／一次消費者／食物連鎖／有機物 |
| 分解者 | 生物の死がいや排出物に含まれる有機物を無機物へ分解する菌類・細菌類など。呼吸によってエネルギーを得ながら、物質を環境へ戻す。食物網の外にいるわけではない。**関連語：**菌類／細菌類／無機物／物質循環 |
| 食物連鎖と食物網 | 食べる・食べられる一列のつながりが食物連鎖、複数の連鎖が網状に結びついたものが食物網。矢印は多くの場合、食べられる生物から食べる生物へ、物質・エネルギーの移動方向に引く。**関連語：**生産者／消費者／エネルギー／捕食 |
| 栄養段階が上がると個体数が減りやすい理由 | 生物が得たエネルギーの多くは呼吸・運動・熱などに使われ、次の栄養段階へ渡るのは一部だけだから。必ず個体数が減るとは限らないので、総量・生物量で考えることも重要。**関連語：**栄養段階／エネルギー流／生物量／食物連鎖 |
| 生態ピラミッド | 生産者から高次消費者へ、個体数・生物量・エネルギー量などを積み上げた図。何の量を表すかを確認する。個体数ピラミッドは大木1本に昆虫多数のような逆転もありうる。**関連語：**生物量／エネルギー量／栄養段階／生産者 |
| 炭素の循環 | 植物が光合成で二酸化炭素を有機物に取り込み、食物連鎖で移動する。生物の呼吸・分解・燃焼により二酸化炭素として環境へ戻る。物質は循環する。**関連語：**光合成／呼吸／分解／燃焼 |
| 物質循環とエネルギー流の違い | 炭素などの物質は生産者・消費者・分解者と環境の間を循環する。一方、エネルギーは太陽から入り、各段階で熱として失われ、一方向に流れるため循環しない。**関連語：**物質循環／太陽エネルギー／熱／生態系 |
| 生物数のつり合い | 捕食者が増えると被食者が減り、やがて餌不足で捕食者も減るなど、相互作用によって変動する。一定数で固定されるのではなく、時間とともに増減しながら範囲内に保たれる。**関連語：**捕食者／被食者／個体群／食物網 |
| 外来種 | 本来の分布域の外へ人間活動によって持ち込まれた生物。すべてが有害ではないが、在来種を捕食・競争したり交雑したりして生態系へ大きな影響を与えるものがある。**関連語：**在来種／生物多様性／競争／生態系 |
| 生物多様性 | 遺伝子・種・生態系の各段階に多様性があること。食料・医薬品・水質浄化などの基盤にもなる。単に『生物の種類数が多い』だけより広い概念。**関連語：**遺伝的多様性／種多様性／生態系多様性／保全 |
