## 読み進め方

| 表 | 裏 |
|---|---|
| <ruby>減数分裂<rp>（</rp><rt>げんすうぶんれつ</rt><rp>）</rp></ruby> | 生殖細胞がつくられるときに、染色体数が体細胞の半分になる特別な細胞分裂。受精で精子と卵の染色体が合わさり、受精卵では元の数に戻るため、世代ごとに倍増しない。**関連語：**生殖細胞／染色体数／受精／体細胞分裂 |
| <ruby>無性生殖<rp>（</rp><rt>むせいせいしょく</rt><rp>）</rp></ruby> | 雌雄の生殖細胞の受精を伴わず、1個体から子ができる生殖。分裂・出芽・栄養生殖などがあり、子は親とほぼ同じ遺伝情報をもつクローンになる。環境が急変すると一斉に不利になりうる。**関連語：**クローン／分裂／出芽／栄養生殖 |
| 分裂と出芽 | 分裂は親個体がほぼ同じ大きさの複数個体に分かれる方法で、アメーバなど。出芽は親の体の一部がふくらんで新個体になる方法で、酵母やヒドラなど。どちらも<ruby>無性生殖<rp>（</rp><rt>むせいせいしょく</rt><rp>）</rp></ruby>。**関連語：**無性生殖／アメーバ／酵母／ヒドラ |
| 栄養生殖 | 植物が根・茎・葉など栄養器官の一部から新個体をつくる<ruby>無性生殖<rp>（</rp><rt>むせいせいしょく</rt><rp>）</rp></ruby>。ジャガイモの塊茎、イチゴのほふく茎、サツマイモの根など。種子を経ない。**関連語：**無性生殖／塊茎／ほふく茎／クローン |
| <ruby>有性生殖<rp>（</rp><rt>ゆうせいせいしょく</rt><rp>）</rp></ruby> | 精子と卵など雌雄の生殖細胞が受精し、新しい個体ができる生殖。両親から遺伝情報を受け継ぐため、子に多様な組み合わせが生じる。**関連語：**精子／卵／受精／遺伝的多様性 |
| 生殖細胞と体細胞 | 生殖細胞は精子・卵など次世代形成に関わる細胞で、染色体数は体細胞の半分。受精で両者が合体すると、受精卵の染色体数はその生物本来の体細胞と同じになる。**関連語：**精子／卵／染色体数／受精卵 |
| 受精と発生 | 精子の核と卵の核が合体するのが受精で、できた受精卵が細胞分裂を繰り返し、組織や器官をつくって個体になる過程が発生。受精卵は最初の1細胞である。**関連語：**受精卵／細胞分裂／<ruby>胚<rp>（</rp><rt>はい</rt><rp>）</rp></ruby>／発生 |
