| 表 | 裏 |
|---|---|
| 種子植物 | 花を咲かせ、種子でふえる植物。<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>が<ruby>子房<rp>（</rp><rt>しぼう</rt><rp>）</rp></ruby>の中にある<ruby>被子植物<rp>（</rp><rt>ひししょくぶつ</rt><rp>）</rp></ruby>と、子房がなく胚珠がむき出しの<ruby>裸子植物<rp>（</rp><rt>らししょくぶつ</rt><rp>）</rp></ruby>に分かれる。**関連語：**被子植物／裸子植物／胚珠／種子 |
| <ruby>被子植物<rp>（</rp><rt>ひししょくぶつ</rt><rp>）</rp></ruby>と<ruby>裸子植物<rp>（</rp><rt>らししょくぶつ</rt><rp>）</rp></ruby> | 被子植物は<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>が子房内にあり、受精後に<ruby>子房<rp>（</rp><rt>しぼう</rt><rp>）</rp></ruby>が果実になる。裸子植物は子房がなく胚珠がむき出しで、マツ・イチョウ・ソテツなどが代表。裸子植物にも花に相当する生殖器官はある。**関連語：**胚珠／子房／果実／マツ |
| マツの花と種子 | 雄花の花粉が風で雌花の<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>に届いて受粉する。雌花のりん片には胚珠がむき出しでつき、<ruby>子房<rp>（</rp><rt>しぼう</rt><rp>）</rp></ruby>がないため果実はできない。松かさは果実ではない。**関連語：**<ruby>裸子植物<rp>（</rp><rt>らししょくぶつ</rt><rp>）</rp></ruby>／雄花／雌花／胚珠 |
| <ruby>双子葉類<rp>（</rp><rt>そうしようるい</rt><rp>）</rp></ruby>と<ruby>単子葉類<rp>（</rp><rt>たんしようるい</rt><rp>）</rp></ruby> | <ruby>被子植物<rp>（</rp><rt>ひししょくぶつ</rt><rp>）</rp></ruby>を<ruby>子葉<rp>（</rp><rt>しよう</rt><rp>）</rp></ruby>の数で分ける。双子葉類は子葉2枚・網状脈・主根と側根が典型、単子葉類は子葉1枚・平行脈・ひげ根が典型。茎の<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>の並び方も異なる。**関連語：**子葉／葉脈／根／維管束 |
| <ruby>双子葉類<rp>（</rp><rt>そうしようるい</rt><rp>）</rp></ruby>の<ruby>合弁花類<rp>（</rp><rt>ごうべんかるい</rt><rp>）</rp></ruby>と<ruby>離弁花類<rp>（</rp><rt>りべんかるい</rt><rp>）</rp></ruby> | 花弁が根元までつながるものを合弁花類（タンポポ・ツツジなど）、花弁が1枚ずつ離れるものを離弁花類（アブラナ・サクラなど）という。花弁がない植物にはこの区分を直接使わない。**関連語：**双子葉類／合弁花類／離弁花類／花弁 |
| シダ植物 | <ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>と根・茎・葉の区別があり、種子をつくらず胞子でふえる。葉の裏などに胞子のうが集まる。受精には水が必要で、日陰の湿った場所に多い。**関連語：**胞子／維管束／胞子のう／コケ植物 |
| コケ植物 | 種子をつくらず胞子でふえ、<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>や本当の根をもたない。雌株・雄株が分かれるものが多く、体表から水を吸収するため湿った場所に多い。根のような仮根は体を固定する。**関連語：**胞子／仮根／維管束／シダ植物 |
| 胞子と種子の違い | 胞子はふつう1個の細胞で、発芽して新しい個体につながる。種子は受精後の<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>が発達したもので、<ruby>胚<rp>（</rp><rt>はい</rt><rp>）</rp></ruby>と養分を含み、乾燥に耐えて広がりやすい。**関連語：**胞子／種子／胚／受精 |
| 植物の分類手順 | まず種子をつくるかで分け、種子植物なら<ruby>胚珠<rp>（</rp><rt>はいしゅ</rt><rp>）</rp></ruby>が子房内か、<ruby>被子植物<rp>（</rp><rt>ひししょくぶつ</rt><rp>）</rp></ruby>なら<ruby>子葉<rp>（</rp><rt>しよう</rt><rp>）</rp></ruby>が1枚か2枚かを見る。種子をつくらない植物は<ruby>維管束<rp>（</rp><rt>いかんそく</rt><rp>）</rp></ruby>の有無などでシダ植物とコケ植物を分ける。**関連語：**種子植物／被子植物／<ruby>単子葉類<rp>（</rp><rt>たんしようるい</rt><rp>）</rp></ruby>／シダ植物 |
