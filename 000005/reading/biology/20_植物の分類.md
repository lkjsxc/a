# 植物の分類

## この単元でつかむこと

- 種子植物
- <ruby>被子植物<rt>ひししょくぶつ</rt></ruby>と<ruby>裸子植物<rt>らししょくぶつ</rt></ruby>
- マツの花と種子
- <ruby>双子葉類<rt>そうしようるい</rt></ruby>と<ruby>単子葉類<rt>たんしようるい</rt></ruby>
- シダ植物
- コケ植物
- 植物の分類手順

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 種子植物 | 花を咲かせ、種子でふえる植物。<ruby>胚珠<rt>はいしゅ</rt></ruby>が<ruby>子房<rt>しぼう</rt></ruby>の中にある<ruby>被子植物<rt>ひししょくぶつ</rt></ruby>と、子房がなく胚珠がむき出しの<ruby>裸子植物<rt>らししょくぶつ</rt></ruby>に分かれる。**つながり：**被子植物／裸子植物／胚珠／種子 |
| <ruby>被子植物<rt>ひししょくぶつ</rt></ruby>と<ruby>裸子植物<rt>らししょくぶつ</rt></ruby> | <ruby>被子植物<rt>ひししょくぶつ</rt></ruby>は<ruby>胚珠<rt>はいしゅ</rt></ruby>が<ruby>子房<rt>しぼう</rt></ruby>内にあり、<ruby>受精<rt>じゅせい</rt></ruby>後に子房が果実になる。<ruby>裸子植物<rt>らししょくぶつ</rt></ruby>は子房がなく胚珠がむき出しで、マツ・イチョウ・ソテツなどが代表。裸子植物にも花に相当する生殖器官はある。**つながり：**胚珠／子房／果実／マツ |
| マツの花と種子 | 雄花の花粉が風で雌花の<ruby>胚珠<rt>はいしゅ</rt></ruby>に届いて<ruby>受粉<rt>じゅふん</rt></ruby>する。雌花のりん片には胚珠がむき出しでつき、<ruby>子房<rt>しぼう</rt></ruby>がないため果実はできない。松かさは果実ではない。**つながり：**<ruby>裸子植物<rt>らししょくぶつ</rt></ruby>／雄花／雌花／胚珠 |
| <ruby>双子葉類<rt>そうしようるい</rt></ruby>と<ruby>単子葉類<rt>たんしようるい</rt></ruby> | <ruby>被子植物<rt>ひししょくぶつ</rt></ruby>を子葉の数で分ける。<ruby>双子葉類<rt>そうしようるい</rt></ruby>は子葉2枚・網状脈・主根と側根が典型、<ruby>単子葉類<rt>たんしようるい</rt></ruby>は子葉1枚・平行脈・ひげ根が典型。茎の<ruby>維管束<rt>いかんそく</rt></ruby>の並び方も異なる。**つながり：**子葉／葉脈／根／維管束 |
| <ruby>双子葉類<rt>そうしようるい</rt></ruby>の<ruby>合弁花類<rt>ごうべんかるい</rt></ruby>と<ruby>離弁花類<rt>りべんかるい</rt></ruby> | 花弁が根元までつながるものを合弁花類（タンポポ・ツツジなど）、花弁が1枚ずつ離れるものを離弁花類（アブラナ・サクラなど）という。花弁がない植物にはこの区分を直接使わない。**つながり：**<ruby>双子葉類<rt>そうしようるい</rt></ruby>／合弁花類／離弁花類／花弁 |
| シダ植物 | <ruby>維管束<rt>いかんそく</rt></ruby>と根・茎・葉の区別があり、種子をつくらず胞子でふえる。葉の裏などに胞子のうが集まる。<ruby>受精<rt>じゅせい</rt></ruby>には水が必要で、日陰の湿った場所に多い。**つながり：**胞子／維管束／胞子のう／コケ植物 |
| コケ植物 | 種子をつくらず胞子でふえ、<ruby>維管束<rt>いかんそく</rt></ruby>や本当の根をもたない。雌株・雄株が分かれるものが多く、体表から水を吸収するため湿った場所に多い。根のような仮根は体を固定する。**つながり：**胞子／仮根／維管束／シダ植物 |
| 胞子と種子の違い | 胞子はふつう1個の細胞で、発芽して新しい個体につながる。種子は<ruby>受精<rt>じゅせい</rt></ruby>後の<ruby>胚珠<rt>はいしゅ</rt></ruby>が発達したもので、胚と養分を含み、乾燥に耐えて広がりやすい。**つながり：**胞子／種子／胚／受精 |
| 植物の分類手順 | まず種子をつくるかで分け、種子植物なら<ruby>胚珠<rt>はいしゅ</rt></ruby>が<ruby>子房<rt>しぼう</rt></ruby>内か、<ruby>被子植物<rt>ひししょくぶつ</rt></ruby>なら子葉が1枚か2枚かを見る。種子をつくらない植物は<ruby>維管束<rt>いかんそく</rt></ruby>の有無などでシダ植物とコケ植物を分ける。**つながり：**種子植物／被子植物／<ruby>単子葉類<rt>たんしようるい</rt></ruby>／シダ植物 |
