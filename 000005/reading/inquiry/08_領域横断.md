## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 太陽の光が食物網を動かすまで | 植物が光合成で光エネルギーを有機物の化学エネルギーへ変え、その有機物が食べる関係を通じて生物へ渡る。各段階で呼吸により一部が熱として周囲へ移る。**関連語：**太陽光／光合成／食物網／呼吸 |
| 酸素と二酸化炭素を結ぶ三つの働き | 光合成は二酸化炭素を取り入れ酸素を出す一方、呼吸と燃焼は酸素を使い二酸化炭素を生じる。物質は循環するが、各働きの速さは環境や活動量で変わる。**関連語：**光合成／呼吸／燃焼／炭素循環 |
| 太陽のエネルギーが水循環を動かすまで | 太陽のエネルギーで海・地面の水が蒸発し、植物からも<ruby>蒸散<rp>（</rp><rt>じょうさん</rt><rp>）</rp></ruby>する。水蒸気は大気中を移動して<ruby>凝結<rp>（</rp><rt>ぎょうけつ</rt><rp>）</rp></ruby>・降水し、高低差による流れで川・地下水・海へ戻る。**関連語：**太陽エネルギー／蒸発／蒸散／水の循環 |
| 日射の差から風が生じるまで | 地表の温まり方に差があると、接する空気の温度・密度・気圧に差ができる。空気は気圧の高い側から低い側へ動き、風となる。地球の自転や地形で実際の向きは修正される。**関連語：**日射／温度差／気圧差／風 |
| 気圧・膨張・状態変化で雲を説明する | 上昇した空気は周囲の気圧低下で膨張し、外へ仕事をして温度が下がる。<ruby>露点<rp>（</rp><rt>ろてん</rt><rp>）</rp></ruby>に達すると気体の水蒸気が液体の水滴や固体の氷へ状態変化し、雲として見える。**関連語：**気圧／膨張／露点／状態変化 |
| 雨が地層の材料を運ぶ道筋 | 降水が地表を流れると、流水が岩石・土砂を<ruby>侵食<rp>（</rp><rt>しんしょく</rt><rp>）</rp></ruby>して運搬する。流れが弱まる場所で粒が<ruby>堆積<rp>（</rp><rt>たいせき</rt><rp>）</rp></ruby>し、長い時間に重なって地層の材料になる。**関連語：**降水／侵食／運搬／堆積 |
| 土の粒と浸水リスクを結ぶ考え方 | 一般に粗い粒の間には大きな隙間があり水がしみ込みやすいが、地面の締まり方・下層・傾き・降雨強度でも流出量は変わる。粒の大きさ一つだけで洪水を断定しない。**関連語：**土の粒／浸透／表面流出／洪水 |
| 地球内部の熱が災害と恵みを生むまで | 地球内部の熱に関わるマグマ活動やプレート運動は、火山・地震・山地を生む。噴火や揺れは災害となる一方、温泉・地熱・肥沃な土壌・地形などの恵みにもつながる。**関連語：**地球内部の熱／プレート／火山／地震 |
| 粒子運動から対流が起こるまで | 加熱で粒子運動が活発になり、多くの物質は膨張して密度が小さくなる。流体では軽くなった部分が上昇し、冷たく密度の大きい部分が沈んで対流する。**関連語：**粒子運動／熱膨張／密度／対流 |
| 電池でモーターが回るまでのエネルギー | 電池内の化学変化で化学エネルギーが電気エネルギーへ変わり、電流と磁界の作用でモーターの運動エネルギーになる。同時に一部は抵抗や摩擦で熱・音へ移る。**関連語：**化学電池／電流／磁界／モーター |
| 発電機から家庭の機器までの変換 | タービン等の運動で磁界を変化させ、電磁誘導により電気エネルギーを得る。送られた電気は機器で光・熱・音・運動へ変わり、変換のたび一部が利用目的外の熱になる。**関連語：**発電機／電磁誘導／電気エネルギー／効率 |
| 高い所の水が発電するまで | 高所の水がもつ位置エネルギーが、落下・流下で運動エネルギーになり、水車を回す。発電機で電気エネルギーへ変換されるが、流域環境への影響も資料で評価する。**関連語：**位置エネルギー／流水／タービン／水力発電 |
| 水溶液の粒子が電流を運ぶまで | 電解質が水に溶けて陽イオンと陰イオンになり、電圧を加えると反対符号の電極へ移動する。電極では電子の受け渡しが起こり、回路として電流が続く。**関連語：**電解質／イオン／電極／電気分解 |
| 中和の進み方を複数データで判断する | 指示薬の色だけでなく、pH、温度、加えた体積、沈殿などを合わせて見る。酸とアルカリを混ぜても量がつり合わなければ一方が残り、中性とは限らない。**関連語：**中和／pH／指示薬／量的関係 |
| 食物が細胞のエネルギー源になるまで | 食物は消化で吸収可能な物質になり、小腸から血液へ入る。循環で細胞へ届き、酸素を使う細胞呼吸でエネルギーが取り出され、二酸化炭素などが生じる。**関連語：**消化／吸収／血液循環／細胞呼吸 |
| 根から大気へ水が移る道筋 | 根から吸収された水は主に道管を通って葉へ運ばれ、<ruby>気孔<rp>（</rp><rt>きこう</rt><rp>）</rp></ruby>から水蒸気として<ruby>蒸散<rp>（</rp><rt>じょうさん</rt><rp>）</rp></ruby>する。植物の水移動は土壌と大気を結び、水循環の一部になる。**関連語：**根／道管／気孔／蒸散 |
| 葉のでんぷんと生態系を結ぶ証拠 | 日光を当てた葉ででんぷんが検出されれば、光合成で有機物がつくられた証拠になる。その有機物は植物の成長や、植物を食べる生物の物質・エネルギー源になる。**関連語：**でんぷん／光合成／成長／食物連鎖 |
| 遺伝子から進化までのつながり | 遺伝子は染色体にあり、細胞分裂・生殖を通じて形質に関わる情報が子へ伝わる。遺伝する変異の割合が世代を重ねて集団内で変わることが、進化につながる。**関連語：**遺伝子／染色体／生殖／進化 |
| 分類の共通点が進化の証拠になる理由 | 多くの構造・発生・化石の特徴が共通する生物ほど、共通の祖先をもつという説明と整合しやすい。外見一つだけでなく複数の独立した証拠を合わせる。**関連語：**分類／共通点／化石／共通祖先 |
| 地球の自転を確かめる観察記録 | 太陽・月・星が一日の間に東から西へ動く記録は、地球が西から東へ自転する模型で統一的に説明できる。一つの天体だけでなく複数天体の共通した動きが証拠を強める。**関連語：**自転／日周運動／天体観察／模型 |
| 季節と生物を地球の運動から説明する | 地軸が傾いたまま地球が公転するため、季節で太陽の南中高度と昼の長さが変わり、受ける日射量が変わる。気温や生物の成長・活動の年変化へつながる。**関連語：**公転／地軸／日射量／季節 |
| 月の満ち欠けを月食と区別する証拠 | 満ち欠けは太陽に照らされた月の半面を、地球から見る角度が変わるため毎月起こる。地球の影に月が入る月食は満月のときだけ起こる特別な現象で、毎月は起こらない。**関連語：**月の満ち欠け／月食／太陽光／位置関係 |
| 豪雨時の危険を複数資料から読む | 雨量だけでなく、短時間雨量、土壌の水分、川の水位、地形、上流の降雨、避難情報を合わせる。自分の場所が晴れていても、上流の雨で増水することがある。**関連語：**雨量／河川水位／地形／避難情報 |
| 発電方法を一つの数値だけで選べない理由 | 発電量、安定性、費用、二酸化炭素、廃棄物、土地利用、災害リスクは発電方法ごとに異なる。共通単位・同じ期間の複数資料を比べ、目的と重み付けを示して判断する。**関連語：**発電／エネルギー資源／環境負荷／意思決定 |
