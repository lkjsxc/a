## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 試験管の液を少量にして加熱する理由 | 液が多いと熱が不均一になり、沸騰時に噴き出しやすい。外側の水滴を拭き、口を人へ向けず、炎を一か所へ当て続けない。**つながり：**試験管／加熱／突沸／熱膨張 |
| 危険性が不明な物質を扱う前 | ラベルと指示を確認し、必要な保護具・換気・火気の有無・廃棄方法を決める。正体を確かめるために直接触れる、味見する、むやみに混ぜる操作はしない。**つながり：**ラベル／保護具／換気／薬品安全 |
| 加熱中の実験台を離れない理由 | 炎の立ち消え、沸騰、発火、器具の転倒は短時間で起こりうる。離れる必要があれば先に火・電源を止め、安全な状態を確認して教師へ伝える。**つながり：**加熱／火気／電源／実験監視 |
| 濃い薬品を薄めるときの確認事項 | 薬品ごとの指定手順を守り、保護具を着け、少量ずつ混ぜて発熱や飛散を避ける。特に濃硫酸は必ず酸を水へ少しずつ加え、逆にしない。**つながり：**希釈／発熱／酸／保護眼鏡 |
| 通電後の電熱線へすぐ触れない理由 | 見た目が変わらなくても高温になり、電源を切った後もしばらく熱い。通電時間を守り、冷えたことを確かめてから扱う。**つながり：**電熱線／ジュール熱／通電／やけど |
| 保護眼鏡を外してよい時点 | 加熱・反応・洗浄が終わり、飛散や破損の危険物が片付くまで着用する。自分が操作していなくても、近くで実験が続く間は外さない。**つながり：**保護眼鏡／薬品／加熱／飛散 |
| ガラス器具を使う前の点検 | ひび、欠け、汚れを明るい所で確認する。傷のあるガラスは加熱や力で割れやすく、割れた物は素手で拾わず指示された道具で処理する。**つながり：**ガラス器具／破損／加熱／保護眼鏡 |
| 試験管の口を人へ向けない理由 | 加熱や反応で液体・固体が急に噴き出すことがあるため、自分にも他人にも向けない。試験管を固定せずのぞき込むのも危険である。**つながり：**試験管／加熱／突沸／保護眼鏡 |
| 薬品が目や皮膚に付いた直後 | こすらず、すぐ多量の水で十分に洗い、教師へ報告する。何の薬品かを伝え、自己判断で別の薬品を付けて<ruby>中和<rt>ちゅうわ</rt></ruby>しない。**つながり：**薬品／洗浄／報告／保護眼鏡 |
| 実験後の薬品を元のびんへ戻さない理由 | 使用中に混ざった別物質で元の薬品全体を汚染し、予期しない反応を起こす可能性がある。余りは指定された回収容器へ入れる。**つながり：**薬品／汚染／廃液／化学反応 |
| 廃液を勝手に流してはいけない理由 | 有害物質、重金属イオン、強い酸・アルカリなどは環境や配管へ影響し、混合で危険な反応も起こりうる。種類ごとに指定容器へ分別する。**つながり：**廃液／環境保全／イオン／<ruby>中和<rt>ちゅうわ</rt></ruby> |
| 回路で電源を最後につなぐ理由 | 配線を直している途中の誤接続や短絡、不要な長時間通電を避けるためである。回路図と接続を確認してから電源をつなぎ、変更前には再び外す。**つながり：**回路／電源／短絡／配線確認 |
| 野外観察の服装と危険回避 | 長袖・長ズボン・帽子・歩きやすい靴を基本とし、対象に応じて手袋を使う。未知の生物や物質へ触れたり味見したりせず、崖・道路・水辺から離れ、移動時は班や教師へ伝える。**つながり：**野外観察／保護具／危険生物／安全行動 |
| 野外観察を中止する判断 | 雷、急な増水、強風、噴火情報、崖の落石などの危険があれば、観察の完遂より退避を優先する。事前に天気・避難経路・連絡方法を確認する。**つながり：**野外観察／自然災害／避難／気象情報 |
