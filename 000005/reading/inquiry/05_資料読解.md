# 資料読解

## この単元でつかむこと

- 資料中の事実と主張を分ける
- 図の<ruby>凡例<rp>（</rp><rt>はんれい</rt><rp>）</rp></ruby>を先に読む理由
- 主張・証拠・理由付けの組み立て
- 複数資料が一致しないときの点検
- 資料を同じ条件で比べる
- 標本数が少ない資料の注意
- 欠けたデータを0として扱えない理由
- 相関だけで原因を決められない理由
- 模型から言えることの限界

## カード構成

10枚（比較3・読図1・因果1・誤解対策4・用語1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 資料中の事実と主張を分ける | 数値・観察記録は証拠、そこから導く「原因はAだ」などは主張である。まず資料に直接書かれた事実を抜き出し、主張がその事実で支えられるか確かめる。**関連語：**事実／主張／証拠／解釈 |
| 図の<ruby>凡例<rp>（</rp><rt>はんれい</rt><rp>）</rp></ruby>を先に読む理由 | 色、線種、記号が何を表すかは図ごとに異なる。凡例を確認せず、青を水、赤を高温などと決めつけると誤読する。**関連語：**凡例／記号／天気図／地質図 |
| 主張・証拠・理由付けの組み立て | 結論となる主張、資料から選んだ証拠、科学概念を使って両者を結ぶ理由付けの順に説明する。数値を写すだけでは、なぜ結論を支えるかが不足する。**関連語：**主張／証拠／理由付け／科学概念 |
| 複数資料が一致しないときの点検 | 対象、期間、場所、単位、測定方法、標本数が同じか確認する。条件が違えば数値の不一致は矛盾とは限らず、比較可能な部分だけを使う。**関連語：**複数資料／測定条件／単位／標本 |
| 資料を同じ条件で比べる | 同じ時刻・期間・面積・個体数など、比較の基準をそろえる。総量が大きくても対象数が多いだけなら、一個体当たりでは小さい場合がある。**関連語：**比較条件／単位当たり量／割合／標本数 |
| 標本数が少ない資料の注意 | 偶然や個体差の影響を強く受け、全体の傾向を代表しにくい。対象を増やし、選び方の偏りを減らし、ばらつきも示すと信頼性が上がる。**関連語：**標本数／個体差／偏り／信頼性 |
| 欠けたデータを0として扱えない理由 | 未測定・測定失敗は「値が0」とは異なる。欠測の印を付け、理由を確認し、平均やグラフへ0として入れない。**関連語：**欠測値／ゼロ／平均／データ処理 |
| 相関だけで原因を決められない理由 | AがBを生むほか、BがAを生む、第三の要因が両方を変える、偶然という可能性がある。時間順序、仕組み、条件制御した実験などを追加して因果を検討する。**関連語：**相関／因果／<ruby>交絡要因<rp>（</rp><rt>こうらくよういん</rt><rp>）</rp></ruby>／対照実験 |
| 見かけの関係をつくる第三の要因 | 二量の両方へ影響し、関係があるように見せる要因を<ruby>交絡要因<rp>（</rp><rt>こうらくよういん</rt><rp>）</rp></ruby>という。気温が上がると飲料販売と水難事故が共に増えても、販売が事故の原因とは限らない。**関連語：**交絡要因／相関／因果／条件制御 |
| 模型から言えることの限界 | 模型は注目する構造・関係を単純化して表す。粒子の色や天体間距離など、説明のために変えた部分を現実そのものと思わず、何を表し何を省いたか明示する。**関連語：**模型／単純化／粒子モデル／天体モデル |
