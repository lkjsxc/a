# 測定と誤差

## この単元でつかむこと

- 測るたび不規則に変わるずれ
- 全測定を同じ向きにずらす誤差
- 測定誤差と操作ミスの違い
- 測る量に合う器具の選び方
- 測定前にゼロを確かめる理由
- 測定者を替えて確かめる理由
- 測定値に単位が必要な理由
- 複数回をまとめて測る工夫
- 平均だけで結果を判断できない場合

## カード構成

12枚（用語3・比較2・実験3・因果2・誤解対策1・計算1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 測るたび不規則に変わるずれ | 読み取りやわずかな環境変動で正負にばらつくずれを<ruby>偶然誤差<rt>ぐうぜんごさ</rt></ruby>という。回数を増やして平均すると影響を小さくできるが、完全には消えない。**つながり：**偶然誤差／反復／平均／散らばり |
| 全測定を同じ向きにずらす誤差 | 器具のゼロ点ずれや校正不良のように、値を一方向へ偏らせるものを<ruby>系統誤差<rt>けいとうごさ</rt></ruby>という。回数を増やして平均しても直らず、器具・方法の点検や補正が必要である。**つながり：**系統誤差／ゼロ点／校正／補正 |
| 測定誤差と操作ミスの違い | 誤差は正しく測っても残る不確かさ、操作ミスは目盛の読み違い・条件違反など避けられる失敗である。ミスを「誤差」と呼んで平均へ混ぜず、原因を確認して再測定する。**つながり：**測定誤差／操作ミス／再測定／外れ値 |
| 正確さと精密さの違い | 正確さは真の値に近い程度、精密さは繰り返した値同士がそろう程度である。値が密集していても、ゼロ点がずれていれば精密だが正確でない。**つながり：**正確さ／精密さ／<ruby>系統誤差<rt>けいとうごさ</rt></ruby>／<ruby>偶然誤差<rt>ぐうぜんごさ</rt></ruby> |
| 測る量に合う器具の選び方 | 量の種類、予想される範囲、必要な細かさに合う器具を選ぶ。100 mL程度を正確に量るのに大きなバケツを使うと、目盛が粗く誤差が大きい。**つながり：**測定範囲／最小目盛／精度／器具 |
| 測定前にゼロを確かめる理由 | 何も測っていないときの指示が0でなければ、全測定値が同じ向きにずれる。ゼロ調整できなければ、ずれを記録して補正する。**つながり：**ゼロ点／<ruby>系統誤差<rt>けいとうごさ</rt></ruby>／補正／測定器具 |
| 測定者を替えて確かめる理由 | 同じ対象を同じ手順で別の人も測り、値を比べると、目の位置・判断基準・操作の癖による偏りを見つけられる。値が違えば手順を具体化して再測定する。**つながり：**測定者／<ruby>客観性<rt>きゃっかんせい</rt></ruby>／操作手順／再測定 |
| 最小目盛より細かい桁の扱い | 目盛の間を合理的に見積もれる器具では、最小目盛のさらに一桁程度を推定して記録する。ただし、見分けられない桁を何桁も付け足してはいけない。**つながり：**最小目盛／推定値／有効な桁／精度 |
| 測定値に単位が必要な理由 | 数値だけでは何の量・大きさか決まらない。数値と単位を一組で記録し、表の見出しに単位を置く場合は各欄で省略してよい。**つながり：**物理量／単位／表／測定値 |
| 複数回をまとめて測る工夫 | 振り子10往復など複数回分を一度に測ってから回数で割ると、開始・停止の反応時間が1往復ごとに占める割合を小さくできる。**つながり：**反復測定／平均／振り子／反応時間 |
| 平均だけで結果を判断できない場合 | 平均が同じでも、値の散らばりや外れ値が大きく違う場合がある。元の値、範囲、測定回数も見て、結果が安定しているか判断する。**つながり：**平均／散らばり／外れ値／信頼性 |
| 最大値と最小値から分かること | 最大値−最小値で求める範囲は、測定値の散らばりの大まかな大きさを示す。平均に近い値が多いかまでは分からないため、元データも確認する。**つながり：**範囲／最大値／最小値／散らばり |
