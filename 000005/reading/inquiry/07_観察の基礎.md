# 観察の基礎

## この単元でつかむこと

- 生き物らしさを調べる観点
- 同じところと違うところ
- 季節の変化を公平に比べる観察
- 季節と生物の変化を結び付ける記録
- 影を比べるときにそろえること
- 五感を使う観察の限界
- 観察対象の大きさを伝える記録
- 一回だけでなく続けて観察する理由
- 生物と周りの環境を一緒に見る理由
- 一つの基準で仲間分けする方法
- 気付きから調べられる問いをつくる

## カード構成

12枚（比較4・実験3・因果4・誤解対策1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 生き物らしさを調べる観点 | 一度動いたかだけで決めず、成長する、子を残す、周囲から物質やエネルギーを取り入れるなど、複数の特徴を継続して調べる。種や休眠中の生物のように、その場で動かない生物もいる。**つながり：**生物／成長／継続観察／分類 |
| 同じところと違うところ | 二つ以上の対象を同じ観点で比べると、共通点から仲間をまとめ、相違点から問いを見つけられる。色だけでなく、形・大きさ・数・場所・動きなど観点を明示する。**つながり：**比較／分類／観点／問題発見 |
| 季節の変化を公平に比べる観察 | 同じ場所・同じ種類の生物を、時刻や記録方法をなるべくそろえて繰り返し観察する。対象や場所まで変えると、季節以外の違いが混ざる。**つながり：**季節／定点観察／条件制御／気温 |
| 季節と生物の変化を結び付ける記録 | 日付だけでなく、気温・日当たり・生物の姿や活動を同時に記録する。同時に変わっただけでは気温が唯一の原因とは決められないが、関係を考える証拠になる。**つながり：**季節／気温／生物の活動／相関 |
| 影を比べるときにそろえること | 同じ棒・同じ場所で、時刻、影の向き、先端の位置、長さを記録する。棒の高さや地面の傾きが違う影を、そのまま太陽の位置の違いとはみなせない。**つながり：**太陽／影／時刻／方位 |
| 物と材料を分けて記録する理由 | 「スプーン」は物の用途・形、「鉄」や「木」は材料を表す。同じ物でも材料が違い、同じ材料でも多様な物になるため、性質を調べるときは材料名を区別する。**つながり：**物体／物質／材料／性質 |
| 五感を使う観察の限界 | 色・音・手触りなどは手掛かりになるが、未知の物を味見したり直接かいだり、熱い物へ触れたりしてはいけない。安全でない感覚は器具による測定へ置き換える。**つながり：**観察／測定器具／安全／気体 |
| 観察対象の大きさを伝える記録 | 図を大きく描いても実物が大きいとは限らないため、実際に測った長さや、基準となる物差し・倍率を添える。図の見た目だけで実物大を判断させない。**つながり：**観察記録／尺度／倍率／長さ |
| 一回だけでなく続けて観察する理由 | 成長、天気、月、影などは時間とともに変わる。一回の姿だけでは変化の順序や周期が分からないため、間隔と条件を決めて記録を重ねる。**つながり：**継続観察／時間変化／成長／周期 |
| 生物と周りの環境を一緒に見る理由 | 生物の姿だけでなく、光、水、温度、食べ物、すみかも記録すると、生物が環境と関わって生きる様子を考えられる。見つけた場所だけで原因を断定しない。**つながり：**生物／環境／すみか／生態系 |
| 一つの基準で仲間分けする方法 | 最初に「脚の数」「花のつくり」など全対象へ同じ基準を当て、当てはまる／当てはまらないで分ける。途中で基準を変えると、分類の意味が曖昧になる。**つながり：**分類／基準／共通点／相違点 |
| 気付きから調べられる問いをつくる | 「不思議だ」で止めず、「何を変えると、何がどう変わるか」の形にする。例として「日なたの方が暖かい」から「日光の当たり方で地面の温度はどう変わるか」と問う。**つながり：**気付き／問題発見／変数／予想 |
