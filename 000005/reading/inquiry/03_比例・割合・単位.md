## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 面積の換算で倍率を二乗する理由 | 1 m=100 cmなので、1 m²は縦100 cm×横100 cm=10000 cm²になる。長さの倍率を一度だけ掛ける誤りに注意する。**関連語：**面積／平方メートル／単位換算／圧力 |
| 体積の換算で倍率を三乗する理由 | 立方体の縦・横・高さの三方向すべてを換算するためである。1 m³=(100 cm)³=1000000 cm³で、長さの倍率を三回掛ける。**関連語：**体積／立方メートル／単位換算／密度 |
| 複数の単位が混じる計算の順序 | 式へ代入する前に、長さ・時間・質量などを一つの単位系へそろえる。計算後に求められた単位を確認し、指定された単位へ直すと換算漏れを防げる。**関連語：**単位換算／式／検算／物理量 |
| 倍率をそろえて比例の未知量を求める | 対応する二量の組を確認し、一方が何倍かをもう一方にも掛ける。単位当たり量を先に求めてもよく、交差に掛けるだけで対応関係を見失わない。**関連語：**比例／倍率／単位当たり量／比例定数 |
| 表から比例と反比例を見分ける | 対応する値で、縦÷横が一定なら比例、縦×横が一定なら反比例を疑う。二組だけで決めず複数組を確かめ、測定誤差があればほぼ一定かを見る。**関連語：**比例／反比例／比／積 |
| 公式を安全に変形する方法 | 求めたい文字だけを残すため、等式の両辺へ同じ演算を行う。V=IRからIを求めるなら両辺をRで割り、I=V/Rとする。**関連語：**等式／式変形／オームの法則／逆算 |
| 答えの単位で式を点検する | 式の各量を単位付きで計算し、求めたい量の単位になるか確認する。距離÷時間がm/sになるように、単位が合わなければ換算または式の誤りを疑う。**関連語：**次元／単位／式／検算 |
| 接頭語が表す十の倍数 | k（キロ）は1000倍、c（センチ）は100分の1、m（ミリ）は1000分の1を表す。ただしmは単独ならメートル、接頭語ならミリなので位置で区別する。**関連語：**接頭語／キロ／センチ／ミリ |
| 長さの単位を変える倍率 | 1 m=100 cm=1000 mm。大きい単位から小さい単位へ直すと数値は大きくなり、逆では小さくなる。単位を書いて向きを確かめる。**関連語：**メートル／センチメートル／ミリメートル／単位換算 |
| 立方センチメートルとミリリットル | 1 cm³=1 mLである。また1000 mL=1 Lなので、1000 cm³=1 L。体積を密度や水溶液の計算へ使うとき単位をそろえる。**関連語：**体積／ミリリットル／リットル／密度 |
| グラムとキログラムの換算 | 1 kg=1000 g。kgからgへは1000倍、gからkgへは1000で割る。重さの単位Nへは単純換算できず、質量と重さを区別する。**関連語：**質量／グラム／キログラム／重さ |
| 秒・分・時をそろえる手順 | 1 min=60 s、1 h=60 min=3600 s。式へ代入する前に求める単位へ統一し、十進法のように100で換算しない。**関連語：**時間／秒／分／時 |
| 割合の基準となる量 | 割合=比べる量÷もとにする量である。「何に対して何倍・何％か」を先に言葉で決め、分母と分子を逆にしない。**関連語：**割合／百分率／比／濃度 |
| 百分率を小数へ直す方法 | ％は100分のいくつかを表すため、数値を100で割る。25％=0.25であり、式の最後に％で答えるなら小数を100倍する。**関連語：**百分率／小数／割合／質量パーセント濃度 |
