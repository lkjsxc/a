# エネルギー資源

## この単元でつかむこと

- 発電に共通するエネルギー変換
- 火力発電の変換経路
- 原子力発電の変換経路
- 太陽光発電と風力発電
- 再生可能資源と<ruby>枯渇性<rt>こかつせい</rt></ruby>資源
- エネルギー変換効率

## カード構成

8枚（比較3・因果4・計算1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 発電に共通するエネルギー変換 | 火力・水力・原子力・風力の多くは、タービンなどの運動で発電機を回し、<ruby>電磁誘導<rt>でんじゆうどう</rt></ruby>で電気を得る。太陽光発電は光を直接電気へ変え、回転する発電機を使わない。**つながり：**発電機／電磁誘導／タービン |
| 火力発電の変換経路 | 燃料の化学エネルギー→熱→蒸気の運動→タービンの運動→電気。出力を調整しやすい一方、化石燃料は有限で、燃焼により二<ruby>酸化<rt>さんか</rt></ruby>炭素や大気汚染物質が生じる。**つながり：**化石燃料／タービン／二酸化炭素 |
| 揚水発電が電気を蓄える仕組み | 電力が余るときにポンプで水を上の貯水池へ上げ、位置エネルギーとして蓄える。需要が多いときに水を落として発電する。往復で損失はあるが、大量の<ruby>需給調整<rt>じゅきゅうちょうせい</rt></ruby>に使える。**つながり：**位置エネルギー／蓄電／需給調整 |
| 原子力発電の変換経路 | 核分裂で得たエネルギー→熱→蒸気→タービンの運動→電気。運転時の二<ruby>酸化<rt>さんか</rt></ruby>炭素排出は少ないが、放射性廃棄物・事故リスク・冷却や廃炉を含めて考える。**つながり：**核分裂／<ruby>放射性物質<rt>ほうしゃせいぶっしつ</rt></ruby>／タービン |
| 太陽光発電と風力発電 | 太陽光は光を直接、風力は風の運動を発電機で電気へ変える。どちらも燃料をほぼ使わないが、天候や時刻で出力が変動するため、送電網・蓄電・他電源との組合せが重要。**つながり：**再生可能エネルギー／蓄電／出力変動 |
| 再生可能資源と<ruby>枯渇性<rt>こかつせい</rt></ruby>資源 | 太陽光・風・水など自然の過程で繰り返し補われる資源が再生可能資源。石油・石炭・天然ガス・ウランなど採取可能量が有限なものは<ruby>枯渇性<rt>こかつせい</rt></ruby>資源。再生可能でも環境影響が0とは限らない。**つながり：**化石燃料／太陽光／持続可能性 |
| エネルギー変換効率 | 投入したエネルギーのうち目的に利用できた割合。効率％＝有効利用エネルギー÷投入エネルギー×100。残りは主に熱や音へ変わり、全エネルギー自体が消えるわけではない。**つながり：**エネルギー保存／熱損失／百分率 |
| 変動する発電を安定供給へつなぐ方法 | 太陽光・風力の出力変動に対し、蓄電、広域送電と地域間連系、使う時刻をずらす需要調整、出力を調節できる発電を組み合わせ、需要と供給を常に近づける。**つながり：**蓄電／送電網／<ruby>需給調整<rt>じゅきゅうちょうせい</rt></ruby> |
