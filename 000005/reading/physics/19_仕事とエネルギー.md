## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 力がする仕事 | 力が物体をその力の向きに移動させたとき、仕事W＝力N×力の向きの移動距離m。単位はJ。力と移動が同方向でないときは、その方向の成分を使う。**関連語：**ジュール／力／移動距離 |
| 仕事が0になる場合 | 力を加えても物体が動かない場合、または力と移動方向が垂直な場合、その力のした仕事は0。荷物を水平に運ぶとき、支える上向きの力の仕事は0。疲労とは別の物理量。**関連語：**仕事／移動距離／力の向き |
| 仕事率 | 単位時間あたりにする仕事。仕事率P＝仕事W÷時間s、単位はW。100 Jの仕事を5秒なら20 W。同じ仕事でも短時間で行うほど仕事率は大きい。**関連語：**仕事／ワット／電力 |
| 仕事の原理 | 道具を使って必要な力を小さくしても、その分動かす距離が長くなり、摩擦を無視すれば仕事の量は変わらない。てこ・滑車・斜面に共通する。**関連語：**てこ／滑車／斜面 |
| 位置エネルギー | 高い位置にある物体が持つエネルギー。基準面からの高さと質量が大きいほど大きく、重力による位置エネルギーは「重さN×高さm」でJになる。基準面の選び方に注意。**関連語：**重力／高さ／運動エネルギー |
| 運動エネルギー | 運動している物体が持つエネルギー。質量が大きいほど、速さが大きいほど大きい。特に速さの2乗に比例するため、速さが2倍なら運動エネルギーは4倍。**関連語：**速さ／質量／位置エネルギー |
| 力学的エネルギー保存 | 摩擦や空気抵抗を無視できるとき、位置エネルギー＋運動エネルギーは一定。落下では位置が減った分だけ運動が増える。各エネルギー単独が一定なのではない。**関連語：**位置エネルギー／運動エネルギー／自由落下 |
| 摩擦があるときのエネルギー | 力学的エネルギーの一部が熱や音などへ変換されるため、力学的エネルギーは減る。しかし熱なども含めた全エネルギーは保存される。「エネルギーが消えた」わけではない。**関連語：**摩擦／熱／エネルギー保存 |
