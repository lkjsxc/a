## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 圧力 | 面を垂直に押す力が単位面積あたりどれほど集中しているかを表す。圧力Pa＝力N÷面積m²。同じ力なら面積が小さいほど圧力は大きい。**つながり：**パスカル／面積／垂直抗力 |
| パスカル | 圧力の単位Pa。1 Pa＝1 N/m²、1 hPa＝100 Pa。面積をcm²で与えられたらm²へ直し、1 cm²＝0.0001 m²を使う。**つながり：**圧力／面積換算／気圧 |
| 接地面積と圧力 | 同じ物体なら面を変えて置いても重さは同じだが、接地面積が小さいほど圧力は大きい。面積が半分なら圧力は2倍。力自体が大きくなるわけではない。**つながり：**圧力／反比例／重力 |
| 大気圧で吸盤やストローが働く理由 | 内側の圧力を下げると、外側の大気圧のほうが大きくなり、その圧力差で吸盤は壁へ押し付けられ、飲み物はストロー内を上がる。大気圧は大気の重さによりあらゆる向きにはたらき、海面付近で約1013 hPa。**つながり：**気圧／真空／圧力差 |
| 水圧 | 水の重さによる圧力で、水面から深いほど大きい。同じ深さなら容器の形や向きによらずほぼ同じで、物体にはあらゆる向きからはたらく。**つながり：**深さ／圧力／<ruby>浮力<rt>ふりょく</rt></ruby> |
| <ruby>浮力<rt>ふりょく</rt></ruby> | 液体や気体中の物体が流体から受ける上向きの力。物体の下面の圧力が上面より大きいため生じる。水中でばねばかりの値が減る量が<ruby>浮力<rt>ふりょく</rt></ruby>に等しい。**つながり：**水圧／見かけの重さ／密度 |
| <ruby>浮力<rt>ふりょく</rt></ruby>を決める量 | 同じ液体では、<ruby>浮力<rt>ふりょく</rt></ruby>は押しのけた液体の体積が大きいほど大きい。完全に水中へ沈めた同じ物体なら、深さを変えても浮力はほぼ変わらない。液体の密度も影響する。**つながり：**排除体積／密度／アルキメデスの原理 |
| 浮く・沈むの条件 | 物体の平均密度が液体より小さければ浮き、大きければ沈む。等しければ、流れや他の力がない条件で液体中にとどまる。浮いて静止するときは<ruby>浮力<rt>ふりょく</rt></ruby>＝重力。鉄の船は空気を含む平均密度を小さくしている。**つながり：**密度／浮力／重力 |
| アルキメデスの原理 | <ruby>浮力<rt>ふりょく</rt></ruby>は、物体が押しのけた流体にはたらく重力に等しい。浮力＝流体の密度×排除体積×重力の強さ。SI単位ならkg/m³×m³×N/kg＝Nとなる。**つながり：**浮力／排除体積／密度 |
