## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 音の正体 | 音は物体の振動によって生じ、その振動が周囲へ伝わる現象。音を出している物体を音源という。音叉を水面に触れさせると水が飛び、振動を確かめられる。**つながり：**振動／音源／音の波 |
| 音を伝える物質 | 音は空気・水・固体などの物質の振動として伝わる。真空には振動を受け渡す粒子がないので音は伝わらない。光は真空中も進むため混同しない。**つながり：**振動／真空／光 |
| 音の大きさと<ruby>振幅<rt>しんぷく</rt></ruby> | 振動の中心からの最大のずれを<ruby>振幅<rt>しんぷく</rt></ruby>という。振幅が大きいほど音は大きい。波形では上下の幅に注目し、横方向の間隔である<ruby>振動数<rt>しんどうすう</rt></ruby>とは区別する。**つながり：**振幅／波形／音の高さ |
| 音の高さと<ruby>振動数<rt>しんどうすう</rt></ruby> | 1秒間の振動回数を<ruby>振動数<rt>しんどうすう</rt></ruby>といい、単位はHz。振動数が多いほど高い音、少ないほど低い音になる。同じ時間幅の波形なら、波の個数が多いほど高い。**つながり：**Hz／周期／波形 |
| 波形の読み取り | 縦方向の振れは<ruby>振幅<rt>しんぷく</rt></ruby>＝音の大きさ、同じ横幅に入る波の数は<ruby>振動数<rt>しんどうすう</rt></ruby>＝音の高さを表す。表示の縦・横の尺度が違う波形は、見た目だけで比べない。**つながり：**振幅／振動数／オシロスコープ |
| 周期（振動） | 1回の振動にかかる時間。<ruby>振動数<rt>しんどうすう</rt></ruby>をf Hz、周期をT秒とするとT＝1/f。例えば50 Hzなら周期は1/50秒＝0.02秒。**つながり：**振動数／Hz／波形 |
| 音の速さ | 空気中の音速は常温で約340 m/s。光よりはるかに遅いため、雷は光ってから音が届く。距離＝速さ×時間で計算し、温度などで音速は少し変わる。**つながり：**速さ／雷／<ruby>反射<rt>はんしゃ</rt></ruby>音 |
| <ruby>反射<rt>はんしゃ</rt></ruby>音で距離を求める | 音を出してから<ruby>反射<rt>はんしゃ</rt></ruby>音が戻るまでに、音は目的物までを往復する。距離＝音速×往復時間÷2。÷2を忘れない。**つながり：**音速／反射／距離 |
| 弦の音を高くする方法 | 弦を短くする、細くする、強く張ると<ruby>振動数<rt>しんどうすう</rt></ruby>が大きくなり音が高くなる。強くはじくことは主に<ruby>振幅<rt>しんぷく</rt></ruby>を大きくし、音を大きくする操作である。**つながり：**振動数／振幅／音の高さ |
| 真空容器のブザー実験 | 容器内の空気を抜くほどブザー音は小さくなるが、ブザーの振動自体は見える。音を伝える空気が減るためで、電気が弱くなったからではない。完全な真空でなければ音は残る。**つながり：**真空／媒質／振動 |
