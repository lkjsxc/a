# 測定

## この単元でつかむこと

- 長さの測り方
- 形を変えた物の重さ
- 体積
- 目盛りの読み方
- 質量

## カード構成

7枚（実験3・誤解対策1・用語2・計算1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 長さの測り方 | ものさしの0の線を物体の端に合わせ、目盛りを正面から読む。端が0に合わないときは、両端の値の差を求める。単位を必ず付け、1 cm＝10 mm、1 m＝100 cmとして換算する。**つながり：**目盛り／単位換算／測定誤差 |
| 形を変えた物の重さ | 同じ物なら、丸める・伸ばす・置き方を変えるなど形を変えても重さは変わらない。ちぎれた一部を失ったり、別の物を加えたりすれば、その出入りの分だけ変わる。**つながり：**質量／保存／測定 |
| 体積 | 物体が占める空間の大きさ。液体はメスシリンダーで測り、単位にはmL、cm³、Lなどを使う。1 mL＝1 cm³、1 L＝1000 mLである。**つながり：**メスシリンダー／密度／単位換算 |
| 目盛りの読み方 | 液面と目の高さをそろえて<ruby>視差<rt>しさ</rt></ruby>を防ぐ。学校実験で連続量を測るアナログ器具は、通常は最小目盛りの1/10まで目分量で読むが、器具や指示に従う。デジタル器具は表示された桁まで記録する。**つながり：**視差／メスシリンダー／測定誤差 |
| 不規則な物体の体積 | 水に沈む物体なら、メスシリンダーの水位の増加分が物体の体積になる。物体を完全に沈め、気泡を付けない。水に溶ける物体には使えない。**つながり：**体積／メスシリンダー／<ruby>浮力<rt>ふりょく</rt></ruby> |
| 質量 | 物体そのものの量で、場所が変わっても同じ。上皿てんびんや電子てんびんで測り、gやkgで表す。重力による力である重さとは区別する。**つながり：**てんびん／重さ／密度 |
| 平均値 | 同じ量を何回か測ったとき、測定値の合計を回数で割った値。偶然のばらつきの影響を小さくできるが、器具のずれなど同じ向きの誤差は消せない。**つながり：**測定誤差／反復測定／グラフ |
