# 電流と磁界

## この単元でつかむこと

- 電流が磁界から受ける力
- モーターの原理
- 電磁誘導
- 誘導電流の向き
- 発電機の原理

## カード構成

6枚（因果2・用語3・読図1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 電流が磁界から受ける力 | 電流が磁界と平行でないとき、導線は電流と磁界の両方に垂直な向きに力を受ける。力は直角のとき最大、平行のとき0。電流か磁界だけを逆にすると力も逆になる。**関連語：**モーター／磁界／電流 |
| 電磁力を大きくする方法 | 流す電流を大きくする、磁界を強くする、磁界内の導線を長くする。コイルでは巻き数を増やすことも有効。向きを変える操作と大きさを変える操作を区別する。**関連語：**モーター／コイル／磁界 |
| モーターの原理 | 磁界中のコイルに電流を流すと、コイルの両側が反対向きの力を受けて回転する。整流子が半回転ごとに電流方向を切り替え、同じ向きの回転を続けさせる。**関連語：**電磁力／整流子／エネルギー変換 |
| 電磁誘導 | コイルを貫く磁界が変化すると、コイルに電圧が生じて電流が流れる現象。磁石を止めたままでは流れず、動かす速さ・磁石の強さ・巻き数を増すと誘導電流は大きくなる。**関連語：**誘導電流／発電機／磁束変化 |
| 誘導電流の向き | 磁石をコイルへ近づけるときと遠ざけるときで逆向きになる。N極とS極を入れ替えても逆になる。変化を妨げる向きに磁界を作るのが基本。**関連語：**電磁誘導／レンツの法則／検流計 |
| 発電機の原理 | 磁界中でコイルを回転させ、コイルを貫く磁界を連続的に変化させて電磁誘導を起こす。運動エネルギーを電気エネルギーへ変換し、基本的に交流を得る。**関連語：**電磁誘導／交流／エネルギー変換 |
