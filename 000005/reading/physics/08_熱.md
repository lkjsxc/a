# 熱

## この単元でつかむこと

- 熱伝導
- 対流
- 熱の伝わり方

## カード構成

8枚（用語3・因果4・誤解対策1）

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 熱伝導 | 物質そのものが大きく移動せず、隣り合う部分へ熱が伝わる現象。金属は熱を伝えやすく、木や空気は伝えにくい。金属棒の一端を熱すると順に温まる。**つながり：**導体／断熱／温度差 |
| 対流 | 多くの液体・気体では、温まった部分が膨張して密度が小さくなり上昇し、冷たい部分が下降して全体に熱を運ぶ。固体では対流しない。水の0〜4℃付近など例外もある。**つながり：**密度／熱膨張／流体 |
| 熱膨張 | 多くの物質は温めると体積が増え、冷やすと減る。橋やレールにすき間を設けるのは膨張による変形を防ぐため。質量は温めただけでは変わらない。**つながり：**温度／体積／密度 |
| 熱の伝わり方 | 熱は高温の物体から低温の物体へ移り、温度差を小さくする。伝わり方には伝導・対流・放射があり、同時に起こることもある。**つながり：**熱伝導／対流／放射 |
| 熱放射 | 赤外線などの電磁波で熱が伝わる現象。物質がない真空中でも伝わるため、太陽の熱が地球へ届く。黒くつやのない面は放射を吸収・放出しやすい。**つながり：**赤外線／真空／太陽 |
| 断熱 | 熱の移動を小さくすること。空気は熱を伝えにくいため、発泡材や二重窓、衣服の空気層が役立つ。魔法瓶は伝導・対流・放射をそれぞれ抑える。**つながり：**熱伝導／対流／放射 |
| 温度と熱の違い | 温度は物体の熱さ・冷たさの程度、熱は温度差によって移動するエネルギー。同じ基準温度まで冷やすなら、少量の熱湯より大量のぬるま湯のほうが多くのエネルギーを放出することもある。**つながり：**熱量／比熱／熱平衡 |
| 熱平衡 | 接触した高温物体から低温物体へ熱が移動し、やがて同じ温度になって見かけ上の熱移動が止まった状態。外部との熱の出入りがなければ、失った熱と得た熱は等しい。**つながり：**熱量保存／温度差／比熱 |
