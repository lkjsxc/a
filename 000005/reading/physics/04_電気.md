## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 電気の通り道 | 乾電池の＋極から導線・豆電球などを通り、−極まで切れ目なくつながった道を回路という。どこか一か所でも切れると電流は流れない。**つながり：**回路／電流／スイッチ |
| 導体と不導体 | 電流を通しやすい物質が導体、通しにくい物質が不導体。金属や黒鉛は導体、ガラス・ゴム・乾いた木などは不導体。金属だけが導体とは限らない。**つながり：**電流／金属／絶縁体 |
| 直列つなぎ | 部品を分かれ道のない一本道につなぐ方法。豆電球2個の直列では同じ電流が順に流れ、一方を外すと全体が消える。乾電池の直列つなぎでは電圧が加わる。**つながり：**並列つなぎ／電流／電圧 |
| 並列つなぎ | 回路に分かれ道を作って部品をつなぐ方法。枝分かれした各部分には同じ電圧がかかり、一方の豆電球を外しても他方は点灯する。家庭の器具も並列につながる。**つながり：**直列つなぎ／電圧／家庭回路 |
| 乾電池の直列つなぎ | 一方の＋極と他方の−極をつなぐ。向きをそろえた2個なら電圧は1個の約2倍になり、豆電球は明るくなりやすい。逆向きにつなぐと電圧が打ち消し合う。**つながり：**電圧／直列回路／極性 |
| 乾電池の並列つなぎ | ＋極どうし、−極どうしをつなぐ。同種・同容量・同じ使用状態の電池を同じ向きでつなぐと、電圧は1個とほぼ同じで同じ器具を長く動かせる。新旧・異種の電池を混ぜるのは危険。**つながり：**並列回路／電圧／電池容量 |
| ショート回路 | 電池の＋極と−極を抵抗の小さい導線で直接つなぐ状態。非常に大きな電流が流れて導線や電池が発熱し、火災や破裂の危険がある。実験で行わない。**つながり：**電気抵抗／発熱／過電流 |
| 乾電池の向きとモーターの回転 | 同じ回路で乾電池の＋極と−極を逆につなぐと、電流の向きが逆になり、モーターの回転方向も逆になる。向き以外の条件をそろえ、乾電池の両極を導線だけで結ばない。**つながり：**乾電池／電流の向き／モーター／ショート回路 |
| 静電気 | 異なる物質をこすったときなどに電子が移動して、物体に電気がたまる現象。同符号の電気どうしは反発し、異符号どうしは引き合う。<ruby>陽子<rt>ようし</rt></ruby>は<ruby>原子核<rt>げんしかく</rt></ruby>から移動しない。**つながり：**電子／電荷／放電 |
| 放電 | たまった電気が空間や導体を通って急に移動する現象。火花放電、雷、真空放電などがある。乾燥時は電荷が逃げにくく静電気がたまりやすい。**つながり：**静電気／雷／電子 |
| 電流の向きと電子の向き | 電流の向きは回路の外部で＋極から−極へと定義する。金属中の自由電子は−極から＋極へ移動し、電流と逆向き。定義が電子発見より先に決まったためである。**つながり：**自由電子／電流／極性 |
| 電流 | 電荷の流れの大きさ。単位はA（アンペア）で、1 A＝1000 mA。回路のある点を1秒間に通る電荷が多いほど電流が大きい。電流計で測る。**つながり：**アンペア／電流計／電子 |
| 電圧 | 電流を流そうとするはたらきの大きさで、2点間の電位差。単位はV（ボルト）、電圧計で測る。電圧が同じでも抵抗が違えば電流は異なる。**つながり：**ボルト／電圧計／オームの法則 |
| 電気抵抗 | 電流の流れにくさ。単位はΩ（オーム）。同じ電圧なら抵抗が大きいほど電流は小さい。抵抗器では電気エネルギーが熱へ変換される。**つながり：**オーム／電流／ジュール熱 |
| オームの法則 | 導体の温度などが一定なら、流れる電流Iは加えた電圧Vに比例する。V＝IR、I＝V/R、R＝V/I。VはV、IはA、RはΩにそろえる。**つながり：**電圧／電流／抵抗 |
| V-Iグラフ | オームの法則に従う抵抗器では、横軸I・縦軸Vなら原点を通る直線で、傾きV/Iが抵抗。横軸V・縦軸Iなら傾きは1/Rなので軸を必ず確認する。**つながり：**オームの法則／傾き／抵抗 |
| 導線の抵抗を変える条件 | 同じ材質・温度なら、導線が長いほど抵抗は大きく、断面積が大きいほど小さい。材質や温度でも変わる。太い導線は電流の通り道が広い。**つながり：**抵抗／長さ／断面積 |
| 直列回路の電流 | 分かれ道がないため、回路のどの点でも電流は等しい。I＝I₁＝I₂。各抵抗で電流が「使われて減る」のではなく、電気エネルギーが変換される。**つながり：**直列回路／電圧／電荷保存 |
| 直列回路の電圧 | 電源電圧は各抵抗にかかる電圧の和。V＝V₁＋V₂。直列の各抵抗には同じ電流が流れるため、抵抗が大きい部分ほど電圧も大きく分配される。**つながり：**直列回路／電圧分配／オームの法則 |
| 直列回路の合成抵抗 | 直列につないだ抵抗の合成抵抗はR＝R₁＋R₂＋…。抵抗を増やすほど全体の抵抗は大きくなり、同じ電源電圧なら回路全体の電流は小さくなる。**つながり：**直列回路／オームの法則／電流 |
| 並列回路の電流 | 分岐前の電流は各枝を流れる電流の和。I＝I₁＋I₂。抵抗が小さい枝ほど大きな電流が流れる。合流後は再び枝電流の合計になる。**つながり：**並列回路／分岐／電荷保存 |
| 並列回路の電圧 | 各枝の両端が同じ2点につながるため、各枝と電源の電圧は等しい。V＝V₁＝V₂。家庭の器具が並列なのは、各器具に一定の電圧をかけ独立に使うため。**つながり：**並列回路／家庭回路／電流 |
| 並列回路の合成抵抗 | 2抵抗なら1/R＝1/R₁＋1/R₂、またはR＝R₁R₂/(R₁＋R₂)。合成抵抗は必ず最小の枝抵抗より小さい。等しいRを2本並列ならR/2。**つながり：**並列回路／合成抵抗／オームの法則 |
| 直列・並列の合成抵抗の見分け | 直列は大きくなるので足し算、並列は通り道が増えるので最小の抵抗より小さくなる。この大小関係を使えば計算ミスを検出できる。**つながり：**直列回路／並列回路／合成抵抗 |
| 電流計のつなぎ方 | 測りたい部分に直列につなぎ、＋端子から電流を入れる。予想できないときは最大の−端子から始める。電流計を電源へ直接並列につなぐと大電流が流れ危険。**つながり：**直列接続／端子／過電流 |
| 電圧計のつなぎ方 | 電圧を測りたい部分の両端に並列につなぎ、＋側を＋端子へ入れる。内部抵抗が大きく、回路を流れる電流をほとんど変えない。予想できないときは最大レンジから。**つながり：**並列接続／端子／電位差 |
| 電流計・電圧計の目盛り | 接続した端子の最大値に合わせて尺度を読み替える。目盛り板が0〜3で3 A端子ならそのまま、300 mA端子なら「3」を300 mAと読む。単位換算にも注意。**つながり：**測定レンジ／mA／目盛り |
| 回路図の接続点 | 導線の交点に●があれば接続、単に交差して●がなければ通常は接続していない。部品の位置をずらしても、同じ節点どうしがつながれば同じ回路である。**つながり：**回路図／直列／並列 |
| 複雑な回路の解き順 | まず直列・並列のまとまりを見つけて合成抵抗を求め、全体電流を出す。次に並列部の電圧、枝電流へ戻る。求めた電流・電圧が和や等しさを満たすか検算する。**つながり：**合成抵抗／オームの法則／検算 |
| 電流が流れない枝 | スイッチが開いている枝には閉じた経路がなく電流は0。導線で抵抗器を迂回する短絡路があると、理想的には抵抗器の両端電圧が0となり、ほぼ電流が流れない。**つながり：**開回路／短絡／電位差 |
| 豆電球のV-I特性 | 豆電球は電流が増えるとフィラメントが高温になり抵抗も増えるため、V-Iグラフは直線にならない。常に一定抵抗として扱える抵抗器との違いに注意。**つながり：**フィラメント／抵抗／ジュール熱 |
| 電力 | 電気器具が1秒あたりに変換する電気エネルギー。電力P＝電圧V×電流I、単位はW。1 W＝1 J/s。同じ時間なら電力が大きいほど使う電気エネルギーも大きい。**つながり：**ワット／電力量／電圧 |
| 電力と抵抗の式 | P＝VIにV＝IRを組み合わせるとP＝I²R、P＝V²/R。同じ電流なら抵抗が大きいほど発熱電力が大きく、同じ電圧なら抵抗が小さいほど大きい。条件を確認する。**つながり：**オームの法則／ジュール熱／電力 |
| 電力量 | 一定の電力を時間tだけ使ったときのエネルギーで、電力量＝電力×時間。Wと秒ならJ、Wと時間ならWh。1 Wh＝3600 J。**つながり：**電力／ジュール／kWh |
| キロワット時 | 家庭の電力量に使う単位kWh。1 kWh＝1000 W×3600 s＝3.6×10⁶ J。例：500 Wを2時間使うと1 kWh。kWとkWhを混同しない。**つながり：**電力量／電気料金／電力 |
| ジュール熱 | 電流が抵抗を通ると生じる熱。I・Rなどを一定とみなせるとき、熱量Q＝電力P×時間t＝VIt＝I²Rtで、単位はJ。calを使う問題では与えられた換算に従う。**つながり：**発熱／電力／抵抗 |
| 水温上昇と電熱線 | 電熱線が与えた熱量が同じなら、水の質量が小さいほど温度上昇は大きい。実際は容器や空気へ熱が逃げるため、電気エネルギーのすべてが水の温度上昇に使われない。**つながり：**ジュール熱／熱容量／効率 |
| 家庭用電気器具の並列接続 | 各器具に同じ100 Vがかかり、別々に入切できるよう並列接続される。器具を増やすと全体の合成抵抗は下がり、幹線の合計電流は増える。**つながり：**並列回路／100V／過電流 |
| ブレーカー | 回路に許容量を超える電流が流れたとき、自動的に回路を切って発熱・火災を防ぐ装置。多数の高電力器具を同時に使うと合計電流が大きくなり作動する。**つながり：**過電流／電力／家庭回路 |
| 定格表示 | 「100 V・1200 W」は100 Vで正しく使うと1200 Wを消費するという意味。このとき電流はI＝P/V＝12 A。定格電圧と違う電圧での使用は性能低下や破損の原因。**つながり：**電力／電圧／電流 |
| 直流と交流 | 直流は電流の向きが一定で、乾電池などが供給する。交流は向きと大きさが周期的に変化し、家庭のコンセントでは日本で東日本50 Hz・西日本60 Hzが主。**つながり：**乾電池／周波数／発電機 |
