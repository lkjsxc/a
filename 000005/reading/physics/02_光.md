| 表 | 裏 |
|---|---|
| 光の直進 | 光は同じ物質の中ではまっすぐ進む。小さな穴を通した光の筋や、影ができることから確かめられる。光線は光の進む道筋を矢印付きの線で表したもの。**つながり：**影／光線／<ruby>反射<rt>はんしゃ</rt></ruby> |
| 影のでき方 | 光源からの光が不透明な物体にさえぎられた場所に影ができる。光源に物体を近づけるほど影は大きくなりやすい。半透明な物体は一部の光を通す。**つながり：**光の直進／光源／透明・不透明 |
| 鏡で<ruby>反射<rt>はんしゃ</rt></ruby>する日光 | 鏡に当たった日光は向きを変えて進み、鏡の向きを変えると<ruby>反射<rt>はんしゃ</rt></ruby>した光が届く場所も変わる。日光は直進するので、鏡の向きと明るい部分の位置を対応させて調べる。**つながり：**鏡／反射／日光／光の直進 |
| 日光を集めたときの明るさと暖かさ | 鏡で<ruby>反射<rt>はんしゃ</rt></ruby>した日光を重ねたり虫眼鏡で集めたりすると、光が集まった所は明るくなり、温度も上がる。太陽や強い光を直接見ず、人・生物・燃えやすい物へ光を集めない。**つながり：**集光／明るさ／温度／観察安全 |
| 光の<ruby>反射<rt>はんしゃ</rt></ruby> | 光が物体の表面ではね返る現象。入射光、<ruby>反射<rt>はんしゃ</rt></ruby>光、法線は同一平面上にあり、入射角＝反射角となる。角度は鏡の面ではなく法線から測る。**つながり：**入射角／反射角／法線 |
| 入射角と<ruby>反射<rt>はんしゃ</rt></ruby>角 | 入射角は入射光と法線のなす角、<ruby>反射<rt>はんしゃ</rt></ruby>角は反射光と法線のなす角。反射の法則により常に等しい。鏡面との角度が示されたら90°から引く。**つながり：**反射の法則／法線／平面鏡 |
| 平面鏡の像 | 像は鏡の奥に、物体と鏡の距離と同じだけ離れて見え、大きさも同じ。光が実際に鏡の奥から来るのではなく、<ruby>反射<rt>はんしゃ</rt></ruby>光を後方へ延長した交点に見える<ruby>虚像<rt>きょぞう</rt></ruby>である。**つながり：**虚像／反射／対称 |
| 鏡で全身を見る条件 | 平面鏡で全身を見るのに必要な鏡の縦の長さは、目の位置によらず身長の1/2。頭頂と足先から目へ届く<ruby>反射<rt>はんしゃ</rt></ruby>光を作図すると分かり、鏡から離れても必要な長さは変わらない。**つながり：**平面鏡／反射の作図／相似 |
| <ruby>屈折<rt>くっせつ</rt></ruby> | 光が異なる物質の境界を斜めに通ると、速さが変わって進む向きも変わる現象。空気から水・ガラスへ入ると法線側へ、水・ガラスから空気へ出ると法線から離れる。**つながり：**法線／全<ruby>反射<rt>はんしゃ</rt></ruby>／凸レンズ |
| <ruby>屈折<rt>くっせつ</rt></ruby>角 | <ruby>屈折<rt>くっせつ</rt></ruby>した光と法線のなす角。空気から水へ進むと屈折角は入射角より小さく、水から空気へ進むと大きい。垂直に入射すると向きは変わらない。**つながり：**入射角／法線／屈折 |
| 水中の物体が浅く見える理由 | 水中の物体から出た光が水面で法線から離れる向きに<ruby>屈折<rt>くっせつ</rt></ruby>し、目は光が直進してきたと判断するため、光線を逆向きに延長した位置に物体があるように見える。**つながり：**屈折／<ruby>虚像<rt>きょぞう</rt></ruby>／光の直進 |
| <ruby>全反射<rt>ぜんはんしゃ</rt></ruby> | 水やガラスなど光が遅い物質から空気側へ進むとき、入射角が一定以上になると境界を通り抜けず、すべて<ruby>反射<rt>はんしゃ</rt></ruby>する現象。空気側から水側へでは起こらない。**つながり：**<ruby>屈折<rt>くっせつ</rt></ruby>／臨界角／光ファイバー |
| <ruby>凸<rt>とつ</rt></ruby>レンズ | 中央が厚く、平行な光を集めるレンズ。光軸に平行な光は<ruby>屈折<rt>くっせつ</rt></ruby>後に<ruby>焦点<rt>しょうてん</rt></ruby>を通り、レンズの中心を通る光はほぼ直進する。この2本を使って像を作図する。**つながり：**焦点／<ruby>実像<rt>じつぞう</rt></ruby>／屈折 |
| <ruby>焦点<rt>しょうてん</rt></ruby>と焦点距離 | 光軸に平行な光が凸レンズで<ruby>屈折<rt>くっせつ</rt></ruby>して集まる点が<ruby>焦点<rt>しょうてん</rt></ruby>。レンズの中心から焦点までが焦点距離で、同じレンズなら基本的に一定。レンズの両側に焦点がある。**つながり：**凸レンズ／光軸／<ruby>実像<rt>じつぞう</rt></ruby> |
| <ruby>実像<rt>じつぞう</rt></ruby> | 光が実際に集まってでき、スクリーンに映せる像。凸レンズで物体を<ruby>焦点<rt>しょうてん</rt></ruby>の外側に置くとでき、上下左右が逆の倒立像になる。物体を焦点へ近づけるほど像は遠く、大きくなる。**つながり：**凸レンズ／<ruby>虚像<rt>きょぞう</rt></ruby>／スクリーン |
| <ruby>虚像<rt>きょぞう</rt></ruby> | 光が実際には集まらず、光線を逆向きに延長した位置に見える像。スクリーンには映らない。凸レンズでは物体を<ruby>焦点<rt>しょうてん</rt></ruby>の内側に置くと、正立で拡大した<ruby>虚像<rt>きょぞう</rt></ruby>になる。**つながり：**<ruby>実像<rt>じつぞう</rt></ruby>／焦点／虫眼鏡 |
| 物体が<ruby>焦点<rt>しょうてん</rt></ruby>の2倍より外側 | 凸レンズから物体までの距離が<ruby>焦点<rt>しょうてん</rt></ruby>距離の2倍より大きいと、反対側の焦点の1〜2倍の位置に、倒立で縮小した<ruby>実像<rt>じつぞう</rt></ruby>ができる。**つながり：**凸レンズ／実像／焦点距離 |
| 物体が<ruby>焦点<rt>しょうてん</rt></ruby>距離の2倍の位置 | 物体を凸レンズの2Fに置くと、反対側の2Fに、物体と同じ大きさの倒立<ruby>実像<rt>じつぞう</rt></ruby>ができる。像と物体はレンズをはさんで対称な距離になる。**つながり：**2F／倒立像／<ruby>焦点<rt>しょうてん</rt></ruby> |
| 物体が<ruby>焦点<rt>しょうてん</rt></ruby>と2倍焦点の間 | 凸レンズのFと2Fの間に物体を置くと、反対側の2Fより遠くに、倒立で拡大した<ruby>実像<rt>じつぞう</rt></ruby>ができる。物体をFへ近づけるほど像は遠ざかり拡大する。**つながり：**凸レンズ／拡大像／実像 |
| 物体が<ruby>焦点<rt>しょうてん</rt></ruby>の内側 | 物体を凸レンズと<ruby>焦点<rt>しょうてん</rt></ruby>の間に置くと、物体と同じ側に正立で拡大した<ruby>虚像<rt>きょぞう</rt></ruby>が見える。光は実際には集まらないのでスクリーンには映らない。**つながり：**虫眼鏡／虚像／焦点 |
| 凸レンズの作図 | 物体の先端から①光軸に平行→<ruby>屈折<rt>くっせつ</rt></ruby>後に反対側の<ruby>焦点<rt>しょうてん</rt></ruby>、②レンズ中心→直進、の2本を引く。交点が<ruby>実像<rt>じつぞう</rt></ruby>の先端。<ruby>虚像<rt>きょぞう</rt></ruby>では屈折光を物体側へ延長する。**つながり：**焦点／実像／虚像 |
| スクリーンに像が映らないとき | 物体が<ruby>焦点<rt>しょうてん</rt></ruby>の内側、スクリーン位置が像の位置と不一致、またはレンズ・物体・スクリーンの中心が一直線でない可能性がある。<ruby>虚像<rt>きょぞう</rt></ruby>はスクリーンを動かしても映らない。**つながり：**<ruby>実像<rt>じつぞう</rt></ruby>／虚像／焦点 |
