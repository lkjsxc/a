| 分解（化学変化） | 1種類の物質が2種類以上の別の物質に分かれる化学変化。加熱による熱分解や、電流による電気分解がある。状態変化のように元と同じ物質へ戻るだけではない。**つながり：**熱分解／電気分解／化合 |

| <ruby>化学反応式<rt>かがくはんのうしき</rt></ruby>の合わせ方 | ①正しい化学式を書く、②複雑な物質から元素ごとに原子数を合わせる、③最後に全元素を確認、④係数を最小整数比にする。H₂＋O₂→H₂Oなら2H₂＋O₂→2H₂O。**つながり：**原子数保存／係数／化学式 |

| マグネシウムの燃焼反応 | マグネシウムが強い光を出して燃え、白色の<ruby>酸化<rt>さんか</rt></ruby>マグネシウムになる。2Mg＋O₂→2MgO。粉末などを質量測定する実験では、るつぼのふたを少しずらして加熱し、強い光を直視しない。**つながり：**酸化／酸化マグネシウム／質量比 |
| 銅の<ruby>酸化<rt>さんか</rt></ruby>反応 | 銅粉を空気中で加熱すると、酸素と結びついて黒色の<ruby>酸化<rt>さんか</rt></ruby>銅になる。2Cu＋O₂→2CuO。加熱・冷却・測定を繰り返し、質量が一定なら反応がほぼ完了したと判断する。**つながり：**酸化銅／酸化／質量増加 |
| 鉄と硫黄の化合 | 鉄粉と硫黄粉を少量混ぜ、試験管口を人へ向けず一部を加熱する。赤熱し始めたら加熱をやめても発熱して反応し、黒色のFeSができる。混合物と違い、生成物から磁石で鉄を分けられない。**つながり：**化合／<ruby>硫化<rt>りゅうか</rt></ruby>鉄／混合物 |

| 炭酸水素ナトリウムと炭酸ナトリウムの判別 | どちらも白色固体だが、水溶液へフェノールフタレイン溶液を加えると、より強いアルカリ性の炭酸ナトリウムは赤色が濃く、炭酸水素ナトリウムは薄い。水への溶け方も異なる。**つながり：**熱分解／アルカリ性／指示薬 |

| <ruby>酸化<rt>さんか</rt></ruby> | 中学では物質が酸素と結びつく化学変化。激しく光や熱を出す<ruby>酸化<rt>さんか</rt></ruby>が燃焼で、さびのようにゆっくり進む酸化もある。金属が酸化すると酸素分だけ質量が増える。**つながり：**燃焼／さび／<ruby>還元<rt>かんげん</rt></ruby> |
