## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 水素の元素記号 | H。元素記号は大文字1字で書く。水素分子の化学式はH₂なので、元素記号Hと分子の化学式H₂を区別する。**関連語：**水素／H₂／原子 |
| 炭素の元素記号 | C。炭素原子を表す元素記号で、二酸化炭素CO₂や酸化銅から炭素で酸素を奪う反応などに使う。**関連語：**炭素／CO₂／有機物 |
| 窒素の元素記号 | N。窒素分子の化学式はN₂で、空気中に最も多い気体である。元素記号Nと分子N₂を区別する。**関連語：**窒素／N₂／空気 |
| 酸素の元素記号 | O。酸素分子はO₂、オゾンはO₃で、同じ酸素原子からできても分子のつくりが異なる。**関連語：**酸素／O₂／酸化 |
| <ruby>硫黄<rp>（</rp><rt>いおう</rt><rp>）</rp></ruby>の元素記号 | S。鉄Feと硫黄Sが化合すると硫化鉄FeSになる。日本語名の頭文字ではなく、決められた記号を使う。**関連語：**硫黄／FeS／<ruby>硫化<rp>（</rp><rt>りゅうか</rt><rp>）</rp></ruby> |
| 塩素の元素記号 | Cl。Cは炭素なので、塩素は大文字Cと小文字lを続ける。塩素分子はCl₂、塩化物イオンはCl⁻。**関連語：**塩素／Cl₂／Cl⁻ |
| ナトリウムの元素記号 | Na。英語名の頭文字だけではなく、ラテン語名に由来する。ナトリウムイオンはNa⁺、塩化ナトリウムはNaCl。**関連語：**ナトリウム／Na⁺／NaCl |
| マグネシウムの元素記号 | Mg。最初のMだけを大文字、gを小文字で書く。酸素と反応すると酸化マグネシウムMgOになる。**関連語：**マグネシウム／MgO／燃焼 |
| アルミニウムの元素記号 | Al。Aを大文字、lを小文字で書く。Clの塩素と同様、小文字のlを数字1と取り違えない。**関連語：**アルミニウム／金属／元素 |
| カリウムの元素記号 | K。日本語名の頭文字とは一致しない記号の一つ。カリウムイオンは電子を1個失ったK⁺である。**関連語：**カリウム／K⁺／陽イオン |
| カルシウムの元素記号 | Ca。Cだけなら炭素なので、小文字aまで書く。カルシウムイオンはCa²⁺である。**関連語：**カルシウム／Ca²⁺／石灰石 |
| 鉄の元素記号 | Fe。日本語名の頭文字とは一致せず、ラテン語名に由来する。鉄と<ruby>硫黄<rp>（</rp><rt>いおう</rt><rp>）</rp></ruby>の反応はFe＋S→FeS。**関連語：**鉄／FeS／金属 |
| 銅の元素記号 | Cu。ラテン語名に由来する。銅原子Cuと銅イオンCu²⁺は電荷の有無が異なる。**関連語：**銅／Cu²⁺／酸化銅 |
| <ruby>亜鉛<rp>（</rp><rt>あえん</rt><rp>）</rp></ruby>の元素記号 | Zn。亜鉛と塩酸の反応はZn＋2HCl→ZnCl₂＋H₂。亜鉛イオンはZn²⁺である。**関連語：**亜鉛／Zn²⁺／水素 |
| 銀の元素記号 | Ag。日本語名の頭文字とは一致せず、ラテン語名に由来する。銀イオンはAg⁺である。**関連語：**銀／Ag⁺／金属 |
| バリウムの元素記号 | Ba。Bを大文字、aを小文字で書く。バリウムイオンBa²⁺は硫酸イオンSO₄²⁻と硫酸バリウムの白色沈殿をつくる。**関連語：**バリウム／Ba²⁺／白色沈殿 |
