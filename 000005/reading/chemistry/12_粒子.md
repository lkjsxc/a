## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 原子 | 化学変化でそれ以上分けられない、物質をつくる基本的な粒子。化学変化では原子の組み合わせが変わるだけで、原子の種類と数は保存される。**つながり：**元素／分子／質量保存 |
| 元素 | 同じ種類の原子をひとまとめにした概念。物質を構成する原子の種類を表し、元素記号で示す。元素と単体は異なり、酸素元素は水にも含まれるが、酸素という単体はO₂。**つながり：**原子／元素記号／単体 |
| 分子 | 物質の性質を示す最小のまとまりとして、複数の原子が結びついた粒子。水H₂Oや酸素O₂は分子からなる。一方、塩化ナトリウムや金属は分子を作らない。**つながり：**原子／化学式／分子を作らない物質 |
| 分子をつくらない物質 | 塩化ナトリウムなどのイオン結晶、鉄・銅などの金属は独立した分子を作らず、多数の粒子が連続して並ぶ。化学式NaClやFeは粒子の種類・比を表す。**つながり：**イオン結晶／金属／化学式 |
| 元素記号の書き方 | 1文字目は大文字、2文字目があるときは小文字。Coはコバルト、COは炭素Cと酸素Oからなる一<ruby>酸化<rt>さんか</rt></ruby>炭素を表し意味が異なる。文字の大小を正確に書く。**つながり：**元素／化学式／原子 |
| 重要な元素記号①（一覧） | 水素H、炭素C、窒素N、酸素O、硫黄S、塩素Cl。個別カードで覚えた後、名称と記号を双方向で総復習する。Clのlは小文字のエル。**つながり：**元素／化学式／非金属 |
| 重要な元素記号②（一覧） | ナトリウムNa、マグネシウムMg、アルミニウムAl、カリウムK、カルシウムCa、鉄Fe、銅Cu、<ruby>亜鉛<rt>あえん</rt></ruby>Zn、銀Ag、バリウムBa。個別カードで覚えた後に総復習する。**つながり：**金属／イオン／化学式 |
| 化学式 | 物質を元素記号と数字で表した式。右下の小さい数字は、その粒子内の原子数や原子数の比を示す。数字1は書かない。H₂OはH原子2個とO原子1個。**つながり：**元素記号／分子／原子数 |
| 係数と右下の数字 | 2H₂Oの前の2は水分子2個を表し、式全体にかかるためH原子4個・O原子2個。H₂O₂の右下数字は1分子の組成を変える。係数は変えてよいが右下数字は変えない。**つながり：**<ruby>化学反応式<rt>かがくはんのうしき</rt></ruby>／原子数／化学式 |
