## カード構成

## 読み進め方

表を見て答えを思い浮かべた後、裏の第一文で核を確認し、続く説明で理由・比較・実験条件を補います。最後の「つながり」から少なくとも一語を選び、関係を一文で説明してください。

| 表 | 裏 |
|---|---|
| 空気中の酸素の割合 | 空気の体積のおよそ5分の1、約21％が酸素である。残りの大部分は窒素で、物が燃えると空気中の酸素が使われる。空気全体が燃焼を助ける物質ではない。**関連語：**酸素／窒素／燃焼 |
| 酸素の性質 | 無色・無臭で、水に溶けにくく、空気より少し重い。自身は燃えないが物質の燃焼を助ける。火のついた線香を入れると激しく燃えるので確認できる。**関連語：**助燃性／燃焼／水上置換 |
| 二酸化炭素の性質 | 無色・無臭で、空気より重く、水に少し溶けて弱い酸性を示す。燃焼を支えず、石灰水を白く濁らせる。濃度が高いと窒息の危険がある。**関連語：**石灰水／炭酸／燃焼 |
| 窒素の性質 | 無色・無臭で、空気の約78％を占める。常温では反応しにくく、燃焼を助けない。食品包装に入れて酸化を抑えたり、液体窒素を冷却に使ったりする。**関連語：**空気／酸化防止／アンモニア |
| 水素の性質 | 無色・無臭で、最も密度が小さく、水に溶けにくい。火を近づけると音を立てて燃え、水ができる。空気との混合気体は爆発しやすいため、最初の気体を捨ててから調べる。**関連語：**燃焼／水／上方置換 |
| アンモニアの性質 | 無色で刺激臭があり、空気より軽く、水に非常によく溶けて水溶液はアルカリ性。湿らせた赤色リトマス紙を青くする。毒性があるので直接かがない。**関連語：**アルカリ性／上方置換／噴水実験 |
| 気体の集め方の選択 | 水に溶けにくい気体は水上置換が基本。水に溶けやすい場合、空気より重ければ下方置換、軽ければ上方置換。反応性や安全性も考える。**関連語：**水上置換／上方置換／下方置換 |
| 水上置換法 | 水に溶けにくい気体を、水を満たして逆さにした容器へ集める。空気が混ざりにくく純度が高く、量も水面から分かる。酸素・水素などに適する。**関連語：**酸素／水素／気体の<ruby>溶解度<rp>（</rp><rt>ようかいど</rt><rp>）</rp></ruby> |
| 上方置換法 | 水に溶けやすく空気より軽い気体を、口を下向きにした容器の上方へ集める方法。気体が上がり、空気を下へ追い出す。アンモニアなどに用いる。**関連語：**アンモニア／密度／気体捕集 |
| 下方置換法 | 水に溶けやすく空気より重い気体を、口を上向きにした容器の下方へ集め、空気を上へ追い出す。二酸化炭素や塩素などに用いる。**関連語：**二酸化炭素／塩素／密度 |
| 気体発生装置の最初の気体 | 装置内に最初から空気が入っているため、発生直後の気体は目的の気体と空気の混合物。純度や爆発防止のため、最初の分は集めずに追い出す。**関連語：**水素／気体捕集／安全 |
| 気体のにおいの確かめ方 | 容器へ鼻を直接近づけず、手で気体を少しずつあおいで嗅ぐ。未知の気体や有毒な気体はむやみに嗅がない。アンモニアや塩素は特に注意する。**関連語：**アンモニア／塩素／実験安全 |
