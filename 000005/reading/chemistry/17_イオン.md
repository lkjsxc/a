| 表 | 裏 |
|---|---|
| イオン | 原子や原子団が電子を失ったり受け取ったりして電気を帯びた粒子。電子を失うと<ruby>陽イオン<rt>よういおん</rt></ruby>、受け取ると<ruby>陰イオン<rt>いんいおん</rt></ruby>。<ruby>原子核<rt>げんしかく</rt></ruby>の<ruby>陽子<rt>ようし</rt></ruby>数は化学変化では変わらない。**つながり：**陽イオン／陰イオン／電子 |
| <ruby>陽イオン<rt>よういおん</rt></ruby> | 原子などが電子を失い、正の電気を帯びた粒子。Na⁺、H⁺、Cu²⁺、NH₄⁺など。右上の数字は電荷の大きさで、原子の個数ではない。**つながり：**電子放出／<ruby>陰イオン<rt>いんいおん</rt></ruby>／<ruby>電離<rt>でんり</rt></ruby> |
| <ruby>陰イオン<rt>いんいおん</rt></ruby> | 原子などが電子を受け取り、負の電気を帯びた粒子。Cl⁻、OH⁻、SO₄²⁻など。マイナスは「電子が少ない」のではなく、<ruby>陽子<rt>ようし</rt></ruby>より電子が多い状態。**つながり：**電子受容／<ruby>陽イオン<rt>よういおん</rt></ruby>／<ruby>電離<rt>でんり</rt></ruby> |
| 原子がイオンになるときの電子 | ナトリウム原子は電子1個を失いNa⁺、塩素原子は電子1個を受け取りCl⁻。イオンになるのは電子の出入りであり、<ruby>陽子<rt>ようし</rt></ruby>や<ruby>中性子<rt>ちゅうせいし</rt></ruby>が移動するのではない。**つながり：**Na+／Cl-／電子移動 |
| 重要な<ruby>陽イオン<rt>よういおん</rt></ruby>（一覧） | 1価はH⁺・Na⁺・K⁺・Ag⁺・NH₄⁺、2価はCu²⁺・Mg²⁺・Ca²⁺・Zn²⁺・Ba²⁺。名称と式を個別カードで覚えた後、電荷ごとに総復習する。**つながり：**<ruby>陽イオン<rt>よういおん</rt></ruby>／電荷／<ruby>電離<rt>でんり</rt></ruby> |
| 重要な<ruby>陰イオン<rt>いんいおん</rt></ruby>（一覧） | 塩化物イオンCl⁻、水<ruby>酸化<rt>さんか</rt></ruby>物イオンOH⁻、硫酸イオンSO₄²⁻、硝酸イオンNO₃⁻、炭酸イオンCO₃²⁻。複数原子からなるものは原子団全体で1つのイオン。個別カード習得後の総復習に使う。**つながり：**<ruby>電離<rt>でんり</rt></ruby>／アルカリ性／<ruby>沈殿<rt>ちんでん</rt></ruby> |
| <ruby>電解質<rt>でんかいしつ</rt></ruby>と<ruby>非電解質<rt>ひでんかいしつ</rt></ruby> | 水に溶けたときイオンに分かれ、水溶液が電流を通す物質が<ruby>電解質<rt>でんかいしつ</rt></ruby>。食塩・塩酸・水<ruby>酸化<rt>さんか</rt></ruby>ナトリウムなど。砂糖やエタノールは溶けてもイオンにならず<ruby>非電解質<rt>ひでんかいしつ</rt></ruby>。**つながり：**<ruby>電離<rt>でんり</rt></ruby>／導電性／イオン |
| <ruby>電離<rt>でんり</rt></ruby> | <ruby>電解質<rt>でんかいしつ</rt></ruby>が水に溶けて<ruby>陽イオン<rt>よういおん</rt></ruby>と<ruby>陰イオン<rt>いんいおん</rt></ruby>に分かれること。NaCl→Na⁺＋Cl⁻。水溶液全体では正負の電荷総量が等しく、電気的に中性。**つながり：**電解質／陽イオン／陰イオン |
| 塩化水素の<ruby>電離<rt>でんり</rt></ruby> | 塩化水素HClが水に溶けるとH⁺とCl⁻に<ruby>電離<rt>でんり</rt></ruby>し、塩酸になる。HCl→H⁺＋Cl⁻。酸性の共通性は主にH⁺による。**つながり：**塩酸／水素イオン／酸性 |
| 水<ruby>酸化<rt>さんか</rt></ruby>ナトリウムの<ruby>電離<rt>でんり</rt></ruby> | NaOH→Na⁺＋OH⁻。水<ruby>酸化<rt>さんか</rt></ruby>ナトリウム水溶液はOH⁻を生じるためアルカリ性を示す。固体や濃い水溶液は強い腐食性があるので皮膚に付けない。**つながり：**水酸化物イオン／アルカリ性／<ruby>中和<rt>ちゅうわ</rt></ruby> |
| 硫酸の<ruby>電離<rt>でんり</rt></ruby> | H₂SO₄→2H⁺＋SO₄²⁻。硫酸1個分からH⁺が2個分生じることと、硫酸イオンの電荷が2−であることを対応させる。**つながり：**硫酸イオン／水素イオン／酸性 |
| 水<ruby>酸化<rt>さんか</rt></ruby>カルシウムの<ruby>電離<rt>でんり</rt></ruby> | Ca(OH)₂→Ca²⁺＋2OH⁻。化学式中のかっこ外の2はOH全体が2組あることを示す。石灰水は水<ruby>酸化<rt>さんか</rt></ruby>カルシウムの<ruby>飽和水溶液<rt>ほうわすいようえき</rt></ruby>。**つながり：**水酸化物イオン／石灰水／アルカリ性 |
| <ruby>沈殿<rt>ちんでん</rt></ruby> | 水溶液中のイオン同士が結びつき、水に溶けにくい固体となって現れること。<ruby>沈殿<rt>ちんでん</rt></ruby>は化学変化で、ろ過により液体から分けられる。色や組み合わせがイオン判定に使われる。**つながり：**イオン／ろ過／硫酸バリウム |
| 金属のイオンへのなりやすさ | 金属原子が電子を失って<ruby>陽イオン<rt>よういおん</rt></ruby>になろうとする程度。なりやすい金属ほど電子を放出しやすく、他の金属イオンへ電子を渡してその金属を<ruby>析出<rt>せきしゅつ</rt></ruby>させることがある。**つながり：**陽イオン／電子／金属の置換 |
| Mg・Zn・Fe・Cu・Agのイオン化順 | 中学でよく比べる範囲では、イオンになりやすい順にMg＞Zn＞Fe＞Cu＞Ag。左ほど電子を失いやすく、右側の金属イオンを含む水溶液から金属を<ruby>析出<rt>せきしゅつ</rt></ruby>させやすい。**つながり：**マグネシウム／<ruby>亜鉛<rt>あえん</rt></ruby>／銅イオン |
| 金属と金属イオンの置換条件 | 金属Aが金属Bよりイオンになりやすければ、AをBのイオンを含む水溶液へ入れると、Aは電子を失って溶け、Bのイオンは電子を受け取りBとして<ruby>析出<rt>せきしゅつ</rt></ruby>する。逆の組合せでは起こらない。**つながり：**電子移動／<ruby>酸化<rt>さんか</rt></ruby><ruby>還元<rt>かんげん</rt></ruby>／析出 |
