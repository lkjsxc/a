## 読み進め方

| 表 | 裏 |
|---|---|
| 酸の共通性 | 水溶液中でH⁺を生じ、青色リトマス紙を赤にし、BTBを黄色にする。多くはマグネシウムなどの金属と反応して水素を発生させる。酸性を示すのは水溶液中。**関連語：**水素イオン／指示薬／水素 |
| アルカリの共通性 | 水溶液中でOH⁻を生じ、赤色リトマス紙を青にし、BTBを青にする。手触りを直接確かめてはいけない。水に溶ける塩基をアルカリという。**関連語：**水酸化物イオン／指示薬／中和 |
| 酸性・アルカリ性と電流 | 酸・アルカリの水溶液はイオンを含むため電流を通す。酸性・アルカリ性は色や味そのものではなく、H⁺・OH⁻など水溶液中の粒子に基づく性質。**関連語：**電解質／水素イオン／水酸化物イオン |
| 紫色キャベツ液の色 | 天然の指示薬で、強い酸性では赤〜桃色、中性付近で紫、アルカリ性では青〜緑〜黄系に変化する。厳密な色は濃度や作り方で変わるので、既知液と比較する。**関連語：**指示薬／pH／酸性 |
| 酸と金属の反応 | うすい塩酸や硫酸は、マグネシウム・<ruby>亜鉛<rp>（</rp><rt>あえん</rt><rp>）</rp></ruby>・鉄などと反応して水素を発生させ、金属イオンを含む塩をつくる。銅はうすい塩酸とは通常反応しない。**関連語：**水素／金属イオン／塩 |
| 炭酸塩と酸の反応 | 炭酸カルシウムや炭酸水素ナトリウムなどへ酸を加えると二酸化炭素が発生する。発生気体は石灰水を白く濁らせて確認する。**関連語：**二酸化炭素／石灰水／炭酸カルシウム |
| アンモニウム塩とアルカリ | 塩化アンモニウムなどのアンモニウム塩へ強いアルカリを加えて加熱すると、刺激臭のアンモニアが発生する。NH₄⁺とOH⁻からNH₃とH₂Oができる。**関連語：**アンモニウムイオン／アンモニア／水酸化物イオン |
