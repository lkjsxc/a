# core_first 150枚の選定監査

## 選定基準

- 別の現象や初見資料へ使い回せる概念を優先する。
- 基本用語だけでなく、因果・比較・計算・実験・読図・誤解対策を含める。
- 同義のまとめカードや、大量の独立事項を一度に問う一覧は原則として避ける。
- 探究20・物理35・化学35・生物30・地学30の計150枚とする。
- 最初の20枚で探究の共通技能をつくり、その後は学年順で領域を5枚前後ずつ交替する。
